# Смоук мобильного интерфейса

Ручной набор для проверки того, что ломалось живьём и не ловится type-check'ом: жесты списка
(скролл против тапа), доступность разделов, проекты, встречи, компактные фильтры. Гоняется
локально — CI по Actions заморожен до 01.09.2026 (см. `docs/BACKLOG.md`).

## Зачем именно браузер

Баг, с которого началась работа, воспроизводится **только** реальным touch-жестом: при
вертикальном скролле браузер забирает жест себе и присылает `pointercancel`, а не `pointerup`.
Юнит-тест на React-обработчиках такого не покажет — поэтому проверка идёт touch-событиями через
CDP (`Input.dispatchTouchEvent`), а не `page.mouse` и не синтетическими React-событиями.

## Запуск

1. Dev-сервер miniapp (DEV_MODE-моки, без прода):

   ```bash
   cd miniapp && npx next dev -p 3111
   ```

2. Отдельный Chrome с CDP-портом (свой профиль — чтобы не конфликтовать с chrome-devtools MCP,
   который держит свой профиль заблокированным):

   ```bash
   "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
     --remote-debugging-port=9333 \
     --user-data-dir=/tmp/swarm-e2e-chrome \
     --window-size=430,900 http://localhost:3111/
   ```

3. Прогон:

   ```bash
   cd miniapp && node e2e/mobile-nav.mjs
   ```

Выход `0` — всё зелёное; `1` — есть падение или ошибка в консоли страницы (ошибки консоли
считаются падением: молчаливый `pageerror` в проде выглядит как «просто ничего не произошло»).

## Переменные

| Переменная | Дефолт | Зачем |
|---|---|---|
| `SWARM_E2E_URL` | `http://localhost:3111/` | адрес приложения |
| `SWARM_E2E_CDP` | `http://127.0.0.1:9333` | CDP-эндпоинт запущенного Chrome |

`puppeteer-core` в зависимостях miniapp **не** держим: `e2e/lib.mjs` берёт его из проекта, если он
есть, иначе из кэша `~/.npm/_npx`. Нет ни там, ни там — `npm i -D puppeteer-core`.

## Что проверяется

| Группа | Проверки |
|---|---|
| Жесты строки | вертикальный свайп скроллит и не открывает задачу; тап открывает; горизонтальный свайп открывает шторку и не открывает задачу; тап при открытой шторке её закрывает |
| Каркас | набор табов (Задачи · Проекты · Встречи · Ещё); дом — задачи; поиск доступен с каждого таба и доходит до ответа; все пункты «Ещё» на месте; миграция старых значений `roy_tab` (`search`→Задачи, `book`→Ещё) |
| Проекты | список с прогрессом; вход в проект; быстрое добавление создаёт задачу именно в проекте |
| Встречи | заголовок выше очереди вычитки; даты без ISO; кнопки действий спрятаны под строкой; вертикальный свайп не открывает встречу; тап открывает; правка названия/тезисов и выбор «Общее/Личное» у несогласованной на месте |
| Плотность | управление до первой строки ≤165px (было 199); тач-цель чекбокса ≥38×44 (было 19×19); один FAB на экране; меню охвата содержит линзу, группировку и админ-тумблер; созданная задача без срока видна сразу |
| Десктоп | дашборд-дом на месте, мобильный таб-бар скрыт |
