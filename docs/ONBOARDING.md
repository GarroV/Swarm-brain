# Swarm Brain — быстрый старт

**Swarm Brain хранит встречи, задачи и документы команды в одном месте и отвечает на вопросы обычным языком.** Пользоваться можно из веба, Telegram, Claude Desktop и через рекордер звонков на Mac — база общая. Начинаем с веб-сервиса: там, в одном меню, подключается всё остальное.

🔗 **Сервис:** [swarm-brain.pages.dev](https://swarm-brain.pages.dev)

---

## Перед стартом

Администратор должен заранее добавить твою рабочую почту в нужный воркспейс. Входи именно этим Google-аккаунтом.

> Если при входе видишь **«Доступ запрещён»** — уточни у администратора, добавлена ли почта выбранного Google-аккаунта в нужный воркспейс. Telegram для веб-входа не используется.

---

## Шаг 1. Войди в сервис

1. Открой [swarm-team.app](https://swarm-team.app).
2. Нажми **«Sign in with Google»** и войди рабочей почтой @dodobrands.io (ту, что админ добавил в список доступа).
3. Если сервис предложит настроить вход по Touch ID, пройди подсказки на экране. После входа откроется рабочий стол: задачи, поиск по базе, встречи, дайджест.

## Шаг 2. Открой настройки

Внизу слева — **«Профиль и настройки»**. Здесь подключается всё остальное. Заодно в разделе **«Профиль»** укажи свои **рынки/страны** — от них зависят дайджест и фильтры «мои / по рынкам».

Дальше настраиваем **по порядку** — он важен 👇

---

## Шаг 3. 📅 Google-календарь — делаем первым

**Зачем.** Календарь нужен рекордеру: по нему сервис заранее предложит запись («встреча через N минут»), а в готовых тезисах появятся **название встречи и участники**. Без календаря рекордер работает, но «вслепую».

**Как.** Проверь `Настройки → Google-календарь`. Если календарь уже подключён при Google-входе — переходи дальше. Иначе нажми **«Подключить Google-календарь»** и выбери рабочий Google-аккаунт. Доступ запрашивается **только на чтение событий**.

## Шаг 4. 🎙 Рекордер встреч (Mac)

**Зачем.** Сам пишет звук созвонов на Mac, сервер делает расшифровку и тезисы — готовая встреча приходит в раздел **«Встречи»**, тебе остаётся вычитать и опубликовать.

**Как.**
1. `Настройки → Интеграции → bumblebee — запись встреч (Mac) → Получить команду установки`.
2. Открой **Терминал** (⌘+Пробел → набери «Терминал»), вставь строку, нажми **Enter**.
3. Установщик поставит и откроет готовое приложение **bumblebee**. **Xcode и Command Line Tools не нужны; вводить пароль в Терминале не требуется.** Токен личный — никому не пересылай.
4. Открой **System Settings → Privacy & Security → Screen & System Audio Recording** и включи **bumblebee**. Это обязательный шаг для записи звука собеседников.
5. Полностью закрой bumblebee (**⌘Q**) и открой заново — разрешение начнёт действовать после перезапуска.

## Шаг 5. 🧠 Claude Desktop (MCP)

**Зачем.** Работа с базой прямо в Claude на твоём Mac — поиск по встречам и задачам, сохранение заметок, ответы по делу.

**Как.**
1. `Настройки → Claude Desktop → Получить команду установки` → вставь строку в **Терминал**, нажми Enter (поставит коннектор и перезапустит Claude).
2. Там же нажми **«Инструкции для проекта»** — текст скопируется в буфер.
3. В Claude Desktop: `Projects → New Project` → вставь скопированное в поле **Instructions**.

Теперь в Claude есть сервер **swarm-brain** с инструментами, и он ищет/сохраняет в вашу базу по правилам команды.

## Готово 🎉

Всё настроено. Что попробовать первым:

- **Спроси базу как коллегу** — «что решили по Сербии?» → ответ со ссылками на источники.
- **Проведи созвон** с рекордером — после звонка загляни в «Встречи», вычитай тезисы и опубликуй.
- **Загляни в дайджест** — сводка за неделю по твоим рынкам.

> По желанию можно подключить ещё **Telegram-бот** (тот же аккаунт — заметки, файлы, вопросы, задачи на ходу) и **Granola** (`Настройки → Granola` — импорт заметок встреч). Настраивать не обязательно.
