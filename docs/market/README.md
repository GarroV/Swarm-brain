# «Анализ рынка»: как собирается страна

Раздел показывает рынок быстрого питания страны по образцу хорватского отчёта: карту сетей, открытия и закрытия, пицца-конкурентов, доставку, выручки операторов и реестр точек. Устройство экрана и таблиц описано в [ARCHITECTURE §Анализ рынка](../ARCHITECTURE.md#анализ-рынка), решения владельца — в [decisions/2026-10-02-market-follow-reference-visual.md](../decisions/2026-10-02-market-follow-reference-visual.md).

Этот файл про другое: как довести новую страну до того же уровня и сделать так, чтобы через год её можно было обновить без раскопок.

## Где что лежит

| Что | Где | Правится |
|---|---|---|
| Описание страны: сети, теги OSM, юрлица, источники | `scripts/market/countries/<CC>.ts` | руками, это единственное место |
| Реестр источников: что, откуда, как часто, когда сверено | [SOURCES.md](SOURCES.md) | генерируется из конфигов: `deno run -A scripts/market/sources-doc.ts > docs/market/SOURCES.md`; тест `scripts/market/sources-doc.test.ts` падает, если документ отстал |
| Автоматические сборщики | `scripts/market/adapters/` (у каждого `about`: откуда и что берёт) | код |
| Запуск сборщиков | `scripts/market/run.ts` (`--country`, `--source`, `--since`) | — |
| Ручная часть страны (сводка, события, таблица пицц, доставка…) | снимок `<CC>.import.json`, импорт кнопкой в «Источниках и свежести» → таблица `mkt_editorial` | вне git: `~/Documents/workbench/private/market/` |
| Разведка по странам (реестры, локаторы сетей) | `~/Documents/workbench/private/market/research/` | вне git |
| Полнота страниц | `scripts/market/parity.sql` | — |

Данные ручных источников и внутренние выгрузки Dodo в репозиторий не попадают: репозиторий публичный.

## Порядок работы по стране

1. **Разведка.** Сети страны (международные и локальные от 3 точек, пекарни отдельно), покрытие OpenStreetMap по каждой сети, локаторы сетей с JSON, реестр юрлиц и доступ к отчётности, доставка, цены, события 2021+. Результат — `research/<CC>.md` и `<CC>/sources.json` во workbench.
2. **Конфиг.** `countries/<CC>.ts`: сети с `osmBrands`, юрлица с рег. номерами, источники. У каждого источника — `url`, `note` (что именно берём) и `checked` (дата сверки), если это не очевидно из адаптера. Пересобрать SOURCES.md.
3. **Автоматика сначала.** Всё, что берётся детерминированно, — адаптером по расписанию: OSM, API Dodo, реестры с открытыми данными или API. Новый адаптер — `adapters/<id>.ts` с `about` и тестом на фикстуре.
4. **Модель — только где без неё никак** (решение владельца: ключ OpenAI один, расход минимальный). Поиск локальных сетей и дат открытия, разбор отчёта без машинного формата, тексты ручной части. Результат модели сохраняется и повторно не запрашивается, пока не изменился вход; попадает в очередь кандидатов, человек принимает.
5. **Ручная часть** — по инструкции эталона, в снимок `<CC>.import.json`.
6. **Сверка.** Прогнать `parity.sql` и сравнить строку страны с Хорватией (таблица ниже); проверить экран на стенде в обеих темах и на телефоне. Где страница беднее — либо дособрать, либо записать причину в таблицу «Дыры».

## Dodo: что даёт публичный API

`https://publicapi.dodois.io/<cc>/api/v1/`, без ключа. Есть для HR, RO, EE, RS, SI, BG, ME.

- `unitinfo/all` — пиццерии: адрес, координаты, `BeginDateWork`. **`BeginDateWork` не всегда дата открытия**: в Хорватии API даёт 24.04.2023, а пиццерия открылась 22.03.2024 (журнал вычитки эталона). Уточнённая дата кладётся в ручную часть, блок `location_dates`.
- `FinancialMetrics` — выручка только за прошлый месяц, тот же месяц год назад и итоги года. **Помесячной истории выручки задним числом нет**: она копится еженедельным прогоном с момента подключения страны.
- `orders/countBySource/<y>/<m>/<d>` — заказы за день по каналам (сайт, приложение, ресторан, агрегатор, киоск) за любую прошлую дату. История заказов догружается один раз: `run.ts --source dodo-publicapi --since 2021-01-01`.

Суммы по каналам (средний чек по каналам, блок «операции Dodo» эталона) есть только во внутренних выгрузках Dodo IS — их для страны даёт владелец.

## Дыры

| Страна | Чего нет | Почему | Что нужно |
|---|---|---|---|
| все | помесячная выручка Dodo до подключения | публичный API отдаёт только прошлый месяц | внутренняя выгрузка Sales по странам или ждать накопления |
| все | операции Dodo по каналам в деньгах | только во внутренних выгрузках Dodo IS | выгрузки от владельца |
| RO, EE | даты открытия у большинства точек, ручная часть | страна собрана только автоматикой | довести по порядку выше (Румыния — в плане Балкан) |
