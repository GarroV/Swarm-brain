Swarm Brain «Рой» — командный мозг

01 — Обзор

Зачем это нужно

Институциональное знание расползается по чатам, головам и встречам — новый человек или коллега с другого рынка не может быстро поднять контекст. «Рой» централизует знание и отвечает на вопросы по содержимому базы со ссылками на источники, а не «по памяти».

📥

Захватываем

Переслал боту текст, файл, голос или ссылку — и это уже в общей базе: с кратким содержанием, странами и типом записи.

🔎

Находим

Спрашиваешь по-человечески — система ищет по смыслу и отвечает, ссылаясь на конкретные записи-источники.

✅

Превращаем в дела

Встречи становятся тезисами и задачами с исполнителями; задачи живут на доске со спринтами и сроками.

02 — Поверхности

Где этим пользуются

Четыре точки входа поверх одного общего «мозга». Команда работает там, где ей привычно — данные у всех одни и те же. Нажмите на карточку, чтобы раскрыть, что там можно делать.

  • Сохранить знание: переслать сообщение, текст, документ, голосовое или ссылку — бот сам разберёт и сохранит.
  • Спросить базу на естественном языке и получить ответ со ссылками на источники.
  • Встречи: ревью импортированных встреч (Granola / Read.ai), правка тезисов, подтверждение.
  • Задачи: создать, назначить, посмотреть свои/командные, сменить статус.
  • Команда и онбординг, обратная связь по боту, админка для суперадмина.
Работает на функции swarm-bot
  • Доска задач в четырёх видах: Список, Таймлайн (Gantt), Спринты, Граф.
  • Умный поиск с ответом и сносками; персональный дайджест за период.
  • Вычитка встреч: правка тезисов, выбор «команде / в личное», подтверждение.
  • Профиль, команда, рынки; для админа — управление пользователями и воркспейсами.
  • Открывается внутри Telegram (Mini App) или в обычном браузере (вход через Telegram).
Веб на Cloudflare Pages, данные через swarm-api
  • Поиск по базе, добавление знаний, работа с записями и файлами — как инструменты Claude.
  • Управление задачами и просмотр встреч той же команды.
  • Подключение одной командой из бота (/setup) по личному токену.
  • Видит только свой воркспейс и свои личные записи — изоляция сохраняется.
Работает на функции swarm-mcp
  • Своё лёгкое приложение для Mac: пишет системный звук и микрофон во время созвона.
  • Понимает, какая встреча идёт сейчас (через календарь), и предлагает записать.
  • Расшифровка и тезисы — в облаке (OpenAI), без локальной модели; длинные встречи обрабатываются по частям.
  • Готовые тезисы приходят «на вычитку», запись хранится локально до подтверждения обработки.
  • Установка одной командой из бота (/recordertoken).

03 — Сквозные процессы

Как движется информация

Пять основных потоков — с развилками и ветками. Выберите процесс; шаги читаются сверху вниз, развилки показывают, куда и почему путь расходится.

Когда запускается

Пользователь присылает боту любой контент — пересланное сообщение, текст, файл, голос или ссылку.

1Пришёл контент
Бот сначала решает: это «сохранить» или «спросить». Пересланное сообщение и явное «сохрани / запиши в базу» — всегда сохранение.
развилка по типу
текст Заметка или знание

Длинный текст → краткое содержание, страны и тип. Короткий → лёгкая заметка с ключевыми словами.

файл Документ

TXT / таблицы и т.п. → извлекается содержимое и сохраняется кусками для поиска.

голос Голосовое

Распознаётся речь, отсекаются «галлюцинации» и тишина; пустое не сохраняется.

ссылка URL

Описание ссылки расширяется, чтобы её потом можно было найти по смыслу.

Похожее уже есть в базе за неделю?
Точный дубль → не плодим запись Продолжение от того же автора → дописываем к существующей Новое → создаём запись
✓Сохранено в базу
Запись получает «смысловой отпечаток» (для поиска), страны, тип (встреча / заметка) и приватность (личное / командное). Теперь её можно найти и спросить.
Когда запускается

Пользователь задаёт вопрос боту или в вебе («что мы решили по Болгарии?», «где инструкция по ТВ-бордам?»).

1Вопрос
Система определяет: это поиск по смыслу или вопрос «что нового / последнее».
развилка по типу вопроса
по смыслу Семантический поиск

Ищет не по словам, а по смыслу — находит релевантные записи, даже если формулировка другая.

по времени «Что нового»

«Что я только что сохранил», «что нового в базе» → отдельный путь, сортировка по времени, а не по смыслу.

Что-то нашлось?
Да → ответ строго по найденному, со сносками [1][2] на источники Нет → честно говорит, что ничего не нашёл (не выдумывает)
✓Ответ со ссылками
Краткий ответ + список записей-источников. Можно тут же «уточнить» — задать следующий вопрос в контексте.
Когда запускается

Прошла встреча. Источников три — и все сходятся в один путь: черновик тезисов → вычитка → база → задачи.

три источника встречи
Granola Импорт

Вручную через /granola или автоматический поллер раз в час подтягивает новые заметки.

Read.ai Вебхук

Read.ai сам присылает завершённую встречу — сохраняется автоматически.

Рекордер Запись

Записал звонок → «кто расшифровывает» → облако режет на части, распознаёт речь, отсекает тишину → тезисы.

2Черновик «на согласовании / на вычитке»
Появляются тезисы и авто-название. Встреча ждёт человека — она ещё не в общей базе.
3Вычитка
Правка тезисов и названия, страны, участники. Можно отклонить или сказать «это не встреча → в заметки».
Куда сохранить?
Команде → видит весь воркспейс В личное → только автор
✓В базе + задачи
Встреча попадает в базу знаний (с поиском), а из тезисов автоматически извлекаются задачи с исполнителями — они уходят в процесс «Задачи».
Когда запускается

Появляется дело — извлечённое из встречи или заведённое руками.

откуда берётся задача
из встречи Автоматически

После публикации встречи из тезисов извлекаются поручения и привязываются к ней.

вручную Бот или веб

Визард в боте (название → исполнитель → рынок → срок) или форма на доске.

2Параметры задачи
Исполнитель, страна/рынок, срок, приоритет, личная или командная.
Жизненный цикл по статусам
На проверке → Открыта (уведомление исполнителю) → В работе → Готово
✓Трекинг на доске
Задачи живут в вебе: Список, Таймлайн (Gantt), Спринты и Граф зависимостей. Личные видны только владельцу, командные — всему воркспейсу.
Когда запускается

Сотрудник работает в Claude Desktop и хочет ту же базу под рукой — особенно для больших текстов.

1Подключение по токену
Команда /setup в боте выдаёт личный токен и настраивает Claude одной строкой.
2Те же операции — как инструменты
доступные инструменты
Знания

Найти, добавить, обновить запись, загрузить файл.

Задачи

Создать, изменить, посмотреть список с фильтрами.

Встречи и команда

Список встреч, участники, статистика базы.

✓Изоляция сохраняется
Через Claude человек видит только свой воркспейс и свои личные записи — ровно как в боте и вебе.

Приватность

Личное и командное

У каждой записи и задачи есть видимость: командная (видит весь воркспейс) или личная (только владелец). Личные записи переезжают вместе с человеком при смене рынка.

Изоляция

Граница — это рынок

Все запросы фильтруются по воркспейсу пользователя. Защита доступа реализована в коде на каждом обращении к данным — человек физически не видит чужой рынок.
