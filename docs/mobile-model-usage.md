# «Расход модели» в мобильной админке

В #837 мобильный маршрут `AdminRoute` открывал `AdminScreen` без входа к
существующему `ModelUsagePanel`. На десктопе та же панель доступна из `AdminDesk`.

Мобильный экран использует существующие вкладки «Пространства» / «Расход модели»
и тот же `canSeeMasterSection(me)`, что десктоп. По умолчанию открыты пространства;
запрос расхода выполняется при выборе соответствующей вкладки. Админ пространства
по-прежнему открывает своё пространство через прежний экран.

Подключён готовый `ModelUsagePanel`: период, график, фильтры, журнал и расчёты
остаются общими с десктопом. Системный расход использует прежний
`GET /admin/model-usage?from=…&to=…` без параметра пространства. Метки вкладок
берутся из `spacesDict` по существующим ключам `tabSpaces` и `tabModelSpend`
с EN/RU переводами. Клавиатуру и состояния вкладок обслуживает общий UI-компонент Tabs.

Основание: #311 — учёт в админпанели; #822 — готовая панель с выбором периода
и гранулярности; решение [14.10/19.10](decisions/2026-10-14-workspace-settings-and-keys.md)
сохраняет системный расход в существующем разделе мастер-админа, без ограничения
на ширину экрана. Эта правка восстанавливает навигацию к готовому экрану.
