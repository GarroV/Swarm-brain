# Блок: meet-adapter

## Назначение

Единственное место, которое знает вёрстку Google Meet. Отдельный блок именно поэтому: вёрстка меняется
без предупреждения, и поломка должна чиниться в одном файле, а не по всему боту.

## API-контракт

```ts
export interface PlatformAdapter {
  join(url: string, displayName: string): Promise<void>;
  waitAdmitted(timeoutMs: number): Promise<"admitted" | "denied" | "blocked" | "unavailable" | "timeout" | "captcha">;
  activeSpeaker(): Promise<string | null>;
  isAlone(): Promise<boolean>;
  leave(): Promise<void>;
}
```

Приёмы, взятые из Vexa (Apache-2.0, с атрибуцией): пиннинг локали `?hl=en` + `--lang=en-US` — без него
текстовые селекторы ломаются у пользователя с другим языком; синтетические движения мыши, потому что
тулбар Meet автоскрывается; двухпроходная классификация «пустили / отказал хост / капча».

## Зависимости

`container` (нужен готовый браузер и звук). Внешнее: Playwright 1.63.0, Google Meet.

## Definition of Done блока

| этап | пункт |
| --- | --- |
| 1 | бот заходит в реальную встречу и виден в списке участников как `scriba` |
| 1 | `waitAdmitted` различает четыре исхода, каждый проверен на живой встрече |
| 1 | `activeSpeaker` возвращает имя говорящего; селекторы по `aria-label`/`role`, не по классам |
| 1 | локаль запиннена: проверено, что селекторы работают при другом языке интерфейса |
| 1 | `isAlone` срабатывает, бот выходит через 2 минуты один в звонке |
| 1 | `leave` закрывает вкладку и освобождает ресурсы |
| 1 | вся вёрстка живёт только в этом блоке — проверено границами модулей |
| 3 | адаптер Контур.Толк по тому же интерфейсу |
| 4 | адаптер Zoom (нативный Meeting SDK for Linux вместо веб-клиента) |

## Устройство

| файл | что в нём |
| --- | --- |
| `types.ts` | `PlatformAdapter`, `MeetSnapshot`, `MeetTile` — единственная форма, в которой знание о странице покидает браузер |
| `url.ts` | пиннинг `?hl=en`, отказ от чужой площадки и не-https |
| `dom.ts` | СЕЛЕКТОРЫ и скрапер `collectMeetSnapshot()` — исполняется в контексте страницы, потому самодостаточен |
| `admission.ts` | вердикт двери по снимку: `admitted` / `denied` (отказал хост) / `blocked` (Meet не пустил гостя до лобби, хост заявки не видел) / `unavailable` (встречи нет или кончилась) / `captcha` / `waiting` |
| `speakers.ts` | говорящий и число участников по снимку |
| `alone.ts` | правило «2 минуты один — выходим» (`AloneTimer`) и сторож `watchAlone` |
| `meet.ts` | `MeetAdapter` — Playwright вокруг перечисленного |
| `fixtures/*.html` | страницы-двойники Meet для смоука в живом браузере |
| `smoke-meet.ts` | смоук: реальный Chromium прогоняет адаптер по всем исходам |

**Правило селекторов.** Семантика прежде всего: `role`, `aria-label`, data-атрибуты Meet
(`data-participant-id`, `data-self-name`, `data-audio-level`). Обфусцированные классы меняются с
релизом молча и берутся только там, где семантики нет. Такое место одно — сигнал говорящего (D034):
с 29.09.2026 Meet не отдаёт `data-audio-level`, и индикатор звука плитки читается по классам
элемента `.IisKdb` (`gjg47c` — молчит; `Oaajhc`/`HX2H7`/`wEsLMd`/`OgVli` — говорит). Незнакомый
набор классов — «сигнала нет», не речь и не тишина. Ещё один класс — маркер `notranslate`, последний
в порядке разбора имени.

**Нет сигнала — не тишина.** Нет ни `data-audio-level`, ни опознанного индикатора `.IisKdb` ни на одной плитке → `activeSpeaker` возвращает
`null` и адаптер ГРОМКО говорит об этом один раз. Таймлайн тогда деградирует мягко (сервер без поля
`speakers` работает как раньше), но мы знаем, что он деградировал.

## Контракт страниц-двойников (`fixtures/`)

Каждая — самодостаточный HTML без внешних ресурсов, `<html lang="en">`, английские тексты.

| файл | обязательное содержимое |
| --- | --- |
| `lobby.html` | `input[jsname][type=text][aria-label="Your name"]`; `button[aria-label="Ask to join"]`; кнопки `Turn off microphone` / `Turn off camera`; НЕТ `[data-participant-id]` |
| `waiting.html` | текст «Asking to be let in»; ни поля имени, ни плиток |
| `denied.html` | «Someone in the call denied your request to join» И оставшийся текст лобби «Asking to be let in» И кнопка «Return to home screen» (ловушка: она не отказ) |
| `blocked.html` | живой текст meet.google.com 28.09.2026: «You can’t join this video call», «Your meeting is safe», «Return to home screen» → `blocked` |
| `unavailable.html` | «Check your meeting code» → `unavailable` |
| `captcha.html` | текст ожидания + видимый `iframe[src*="recaptcha"]` 304×78 + второй такой же `display:none` (невидимый капчей не считается) |
| `in-call-speaking.html` | три `[data-participant-id]`: своя с `data-self-name="scriba"`, «Василий Гарро» через `span.notranslate` с `data-audio-level="0.8"`, «Анна» через `aria-label` с `data-audio-level="0"`; панель `[role=list]` с тремя `[role=listitem]`; тулбар (`Leave call`, `Present now`, `People`), который прячется через 1.5 с бездействия (`visibility:hidden`) и возвращается на `mousemove` |
| `in-call-speaking-classes.html` | вёрстка без `data-audio-level` (D034): «Василий Гарро» с индикатором `.IisKdb Oaajhc` (говорит), «Анна» с `.IisKdb gjg47c` (молчит), «Пётр» с незнакомым классом (сигнала нет) — говорящий «Василий Гарро» |
| `in-call-alone.html` | только своя плитка; панель с одним `[role=listitem]`; тулбар с тем же автоскрытием |
| `in-call-no-signal.html` | две плитки с именами и БЕЗ `data-audio-level` где бы то ни было |

Смоук требует живой сети; `SCRIBA_MEET_LIVE=0` пропускает её и выходит кодом 2 — «зелёного нет».

**Чего НЕТ и почему.** Исходы `admitted`, `timeout` и `captcha` на ЖИВОЙ встрече не воспроизведены:
нужен Google-аккаунт и человек, который впускает и отказывает руками (D004). На двойниках и на живой
странице ошибки они проверены, на живой встрече — нет. Это пункт живого прогона T004, не обход.

**Открытая слабость, которую стоит знать.** Живая встреча 29.09.2026 показала: `data-audio-level` в
вёрстке Meet больше нет. Сигнал говорящего теперь — классы индикатора `.IisKdb` (D034), проверены на
живом звонке с двумя людьми: говорящий определялся верно и не слипался. Классы хрупкие: сменит их
Meet — `activeSpeaker` вернёт `null` и скажет об этом громко, стенограмма пойдёт без имён, но не с
чужими именами. Тогда — повторить замер (`diag-speak2.ts` в `~/Documents/workbench/scratch/`).
