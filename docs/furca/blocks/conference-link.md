# Блок: conference-link

## Назначение

Сервер уже отдаёт ссылку на звонок (`join_url`, появилась ради кнопки «Подключиться», #193). Блок
дополняет её тем, чего не хватает боту: какая это площадка и почему ссылки нет, если её нет.
Маленький блок с большим эффектом — он же закрывает часть запланированной Фазы B room-match.

## API-контракт

```ts
// meeting-current/join-link.ts
export function joinLink(ev: GEvent): string | null;                    // существует
export function conferencePlatform(url: string): "meet" | "kontur" | "zoom" | null;  // новое

// ответ meeting-current
{ join_url: string | null, platform: "meet" | "kontur" | "zoom" | null, reason?: "no_conference_link" }
```

Источники ссылки по порядку: `conferenceData.entryPoints[]` (video, https) → `hangoutLink` →
`location` → **`description`** (новое). Площадка по хосту: `meet.google.com` → `meet`,
`ktalk.ru` / `talk.kontur*` → `kontur`, `*.zoom.us` → `zoom`.

## Зависимости

Продуктовых нет. Внешнее: существующие `meeting-current/index.ts`, `join-link.ts` и его тесты.

### Что решено по ходу и почему

- **`platform` и `reason` лежат ВНУТРИ `meeting`, рядом с `join_url`** — план говорит «дополнительно
  к существующему `join_url`», а он лежит в `meeting`. Верхнеуровневый `reason` в этом эндпоинте уже
  занят другим смыслом («почему встречи нет»: `google_not_connected`, `no_ongoing_event`), и класть
  туда же «почему ссылки нет» значило бы сложить два разных ответа в одно поле.
- **Незнакомая площадка — не отказ.** Ссылка на Teams даёт `platform: null`, но `reason` не ставится:
  ссылка есть, кнопка «Подключиться» работает, просто бот туда не ходит (адаптера нет).
- **`description` добавлен в тип `GEvent`** (`select.ts`, одно необязательное поле). Google отдаёт
  описание сам: `listEvents` не задаёт маску полей — проверено чтением `_shared/google-calendar.ts`.

## Замечания, которые вне моих полномочий (диспетчеру)

1. **`reports/check.xml` не существует.** `scripts/check` его не создаёт — в `scripts/` и
   `.github/workflows/` нет ни одного упоминания junit/check.xml. Машинные артефакты прогона
   сейчас только `reports/lcov-server.info` и `reports/coverage-baseline-server.txt`.
2. **`deno lint` краснеет на любом тронутом edge-файле** (`no-import-prefix`): https-импорты —
   канон Swarm, карты импортов у `supabase/functions` нет, а замена на bare-спецификатор
   рискует деплоем. Погасил точечными `deno-lint-ignore` в двух файлах, которые тронул; каждый
   следующий блок упрётся в то же. Решение уровня проекта — не моё.
3. **`deno fmt` на тронутом файле переформатирует его легаси целиком** (ширина по умолчанию 80,
   репозиторий писан по 120). В коммите есть форматные правки `index.ts`/`select.ts`, не
   связанные с задачей, — прямое следствие D013.
4. **База покрытия сервера поднята гейтом автоматически: 85.21 → 87.55.** Планка общая, и после
   слияния она станет общей для всех: параллельные блоки получат конфликт на этой строке и
   более высокий порог, чем тот, под который они работали.
5. **Побочный эффект за пределами эндпоинта:** `swarm-api` (панель «Встречи сегодня») зовёт тот же
   `joinLink`, поэтому ссылка из описания теперь находится и там. Контракт не менялся, тесты
   потребителя зелёные (655 серверных тестов), поведение только богаче.
