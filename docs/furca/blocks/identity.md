# Блок: identity

## Назначение

Даёт `scriba` законную личность на сервере: он приходит со своим токеном, но действует **от имени
человека**. Отдельный блок, потому что это единственное место, где расширяется авторизация, — вся
новая власть собрана здесь и здесь же накрыта блокирующими тестами. Корень графа: без него ни один
серверный вызов бота не проходит.

## Контракт

```ts
// _shared/agent-auth.ts
export type TokenKind = "recorder" | "recorder_prev" | "mcp" | "bot";
export interface AgentIdentity { telegramId: number; groupId: string | null; kind: TokenKind }

export async function resolveActingIdentity(
  supabase: SupabaseClient, req: Request, onBehalfOf?: number,
): Promise<AgentIdentity>;
```

Подмена личности происходит **один раз, на входе**. После неё `identity.telegramId` — человек, и весь
существующий код (десять мест в `meeting-claim`, проверка владельца в `meeting-ingest`, запись статуса
в `meeting-heartbeat`) продолжает работать без правок.

Хранение: **отдельная таблица служебных агентов** (не `allowed_users` — это таблица людей, служебная
строка в ней молча сделала бы бота сотрудником в выборках команды).

## Зависимости

Продуктовых блоков нет — корень графа. Внешнее: существующая `_shared/agent-auth.ts`, таблица
`allowed_users`, Supabase.

## Готовность блока

| этап | пункт |
| --- | --- |
| 1 | миграция таблицы служебных агентов накатана и обратима (только добавление) |
| 1 | `kind` присутствует в `AgentIdentity`; `classifyToken` покрыт тестами на все виды токенов |
| 1 | **блокирующий:** токен `kind: "recorder"` не может передать `on_behalf_of` → 403 |
| 1 | **блокирующий:** бот не может указать человека из чужого воркспейса → отказ |
| 1 | **блокирующий:** токен бота без `on_behalf_of` не даёт прав ни на что |
| 1 | `claim_owner` и `owner_id` после подмены — человек, не бот (проверено тестом) |
| 1 | `bumblebee` прогнан после правок и работает как раньше |
| 1 | secret-review пройден: расширение авторизации осмотрено отдельно |
| 1 | `ARCHITECTURE.md` и `QUICK_REF.md` обновлены тем же коммитом |
