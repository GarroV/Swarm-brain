# Блок: identity

## Назначение

Даёт `scriba` законную личность на сервере: он приходит со своим токеном, но действует **от имени
человека**. Отдельный блок, потому что это единственное место, где расширяется авторизация, — вся
новая власть собрана здесь и здесь же накрыта блокирующими тестами. Корень графа: без него ни один
серверный вызов бота не проходит.

## API-контракт

```ts
// _shared/agent-auth.ts
export type TokenKind = "recorder" | "recorder_prev" | "mcp" | "bot";
export interface AgentIdentity { telegramId: number; groupId: string | null; kind: TokenKind }

export async function resolveActingIdentity(
  supabase: SupabaseClient, req: Request, onBehalfOf?: number,
): Promise<AgentIdentity>;
```

Подмена личности происходит **один раз, на входе**. После неё `identity.telegramId` — человек, и весь
существующий код (десять мест в `meeting-claim`, проверка владельца в `meeting-ingest`, запись статуса
в `meeting-heartbeat`) продолжает работать без правок.

Хранение: **отдельная таблица служебных агентов** (не `allowed_users` — это таблица людей, служебная
строка в ней молча сделала бы бота сотрудником в выборках команды).

## Зависимости

Продуктовых блоков нет — корень графа. Внешнее: существующая `_shared/agent-auth.ts`, таблица
`allowed_users`, Supabase.

## Состояние

**Где стоим (2026-09-26).** T010–T014, T016, T017 закрыты раньше; T015 частично (ниже). **T149 (D017)
закрыт, ждёт приёмки.** Что может человек: вставить в вебе ссылку на Meet / Контур.Толк / Zoom
(`swarm-api` `POST /meeting-invites`) — это одноразовое приглашение на 15 минут; видеть его статус
(`GET /meeting-invites/:id`: pending → taken → used / expired, `meeting_id`). Оркестратор забирает
ожидающие приглашения своего воркспейса (`meeting-invite`, дверь `resolveServiceAgent`).

**Что теперь для агента невозможно.**
- выдать календарное событие за комнатную или ручную встречу (и наоборот) — 400;
- завести календарную встречу на человека, которой нет в его Google-календаре — 403;
- подсунуть свой состав: календарный — из Google, у комнатной и ручной — пустой;
- встать в чужую открытую встречу (календарную — вне календаря человека, комнатную — без него в составе);
- **завести ручную встречу без приглашения**, по приглашению другого человека или воркспейса, по
  истёкшему, погашенному, с подменённой ссылкой — 403 одним текстом; повторно по тому же — 403;
  из N одновременных заявок по одному приглашению проходит ровно одна (условный UPDATE `used_at`);
- забрать приглашения чужого воркспейса или по личному токену (401) / с `X-On-Behalf-Of` (403).
