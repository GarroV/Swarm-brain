# Английский — только для демо; перевод системы отложен

**Дата:** 23.09.2026
**Статус:** принято владельцем

## Решение

Владелец, дословно: **«ок, значит инглиш подождет, хер с ним. но демо нужно на инглише
обязательно»**.

То есть: полноценный перевод продукта на английский **не делаем** (ни сейчас, ни в ближайших
планах), а **демо-витрина обязана быть полностью английской** — без русских протечек.

## Почему так

Вопрос владельца был «если сейчас переводить всю систему в том числе на английский, это больно
будет?». Замер объёма на 23.09.2026 (русские строковые литералы в коде, комментарии и тесты не
в счёт):

| Зона | Уникальных строк | Уже парой `dt()` |
|---|---|---|
| miniapp (интерфейс) | 850 | 458 |
| swarm-api + `_shared` | 382 | 0 |
| бот, дайджесты, вебхуки | 1027 | 0 |
| рекордер (Swift) | 184 | 0 |
| **всего** | **~2400** | ~19% |

Дорого не само переписывание строк, а три вещи:

1. **`dt()` не годится как фундамент** — это хук (`miniapp/src/components/roy/nav.ts:63`),
   работает только внутри React-компонента, а половина строк живёт в утилитах и на сервере.
   В нём нет ни множественных чисел, ни падежей, ни локали дат; язык берётся от флага
   `is_demo`, а не от выбора пользователя. Настоящий i18n потребовал бы словаря, провайдера,
   языка в профиле и прокидывания языка на сервер — 458 уже размеченных пар пришлось бы
   переложить заново.
2. **Две трети объёма — на сервере, и там строки не переводятся как строки.** Сервер отдаёт
   готовый текст (`swarm-api/space-journal.ts:255` — `text: \`Взята в ${cycle}\``); переводить
   надо не строку, а конструкцию — разбирать на код события + параметры.
3. **Данные переводу не поддаются.** Названия проектов, задач, комментарии, стенограммы —
   русские; тезисы принудительно русские (`_shared/tezisy-prompt.ts:98`). Английский интерфейс
   поверх русских данных даёт наполовину английский экран.

## Что из этого следует

- Новый пользовательский текст по-прежнему заводится **парой RU/EN** (правило EN-приоритета,
  CLAUDE.md §7) — но ради витрины, а не ради английской версии продукта.
- Протечки на демо — **дефект**, а не косметика: витрина живёт на англоязычной странице
  портфолио. Реестр протечек и работа по ним — issue #459.
- К полному переводу вернуться только под конкретную задачу (англоязычные пользователи
  в команде), и тогда делать целиком: фундамент → интерфейс → сервер → бот, с механическим
  гейтом на голый русский литерал. Половинчатое состояние хуже обоих.

## Связанное

- `miniapp/src/components/roy/nav.ts:63` — `useDt`, точка переключения языка.
- `supabase/functions/swarm-api/index.ts:637` — `isDemo`, единственное условие английского.
- issue #205 — у рекордера i18n-слоя нет вообще.
