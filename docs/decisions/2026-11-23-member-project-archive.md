# 2026-11-23 — участники архивируют проекты и вкладки доски

## Слова владельца (дословно)

> Возможно тут связаны админские права. давай в целом откроем доступ для удаления проектов. но проекты мы по сути не удаляем, а архивируем

## Поведение

- На доске «Проекты» архивирование вкладки (`sprints.kind=board_tab`) доступно обычному участнику своего пространства. Сервер проверяет пространство и тип строки; тип повторно ограничивает запись. Пространства раздела «Спринты» (`kind=space`) архивирует администратор.
- Архивирование использует существующие `archived_at`/`archived_by`. Проекты, подпроекты, задачи и связи `parent_id`, `project_id`, `project_linked`, `sprint_id` сохраняются. Архив вкладки убирает её из списка; проекты остаются доступны в общем обзоре, как в существующем правиле архивации вкладок.
- Архив проекта убирает с доски его и подпроекты. Доступ определяется существующей видимостью: открытый проект доступен участникам, закрытый — своему автору; группа с чужим закрытым подпроектом защищена прежним отказом.
- В интерфейсе действие называется «Архивировать», подтверждение объясняет сохранение данных. Фронт не отвязывает задачи и не переносит подпроекты на верхний уровень. При отказе сервера объект остаётся на месте и показана ошибка.

Миграция не нужна: схема и серверная архивация существуют с 21.09.2026. Изменение раздела «Проекты» выполнено по прямой просьбе владельца.
