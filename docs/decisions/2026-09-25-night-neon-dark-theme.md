# 2026-09-25 — тёмная тема = ночной неон (как у multa)

**Владелец, дословно:** «давай сделаем сине-бирюзовый неон. в целом в интерфейс я бы добавил его тоже. примерно как мульта в ночной раскраске» → выбран «циан мульты» → «ебаш».

**Решение.** Тёмная тема витрины получает палитру ночной темы multa: сине-чёрный canvas, циан `#00E5FF` как основной цвет с тёмной подписью, свечение через токены `--glow-*` только в тёмной теме. Светлая тема (синий стенд, решение 24.09.2026) не меняется. Фавикон — циановый неон (PR #535).

**Почему так.** Циан ложится рядом с синим стендом как родной акцент; свечение в токенах переключается темой без отдельных стилей — рецепт multa.

Детали реализации — `docs/MINIAPP_ARCHITECTURE.md`, абзац «Тёмная тема = ночной неон».
