# Swarm переезжает с Supabase Cloud на свой сервер, план Pro не берём

**Дата:** 2026-10-13 · **Статус:** принято, действует · **Решение владельца, не техническая деталь**

> ⛔ Не менять без явного решения владельца.

## Повод

12.10 в 22:45 UTC Supabase ограничил проект на Free-плане: egress 10,8 / 5 ГБ, вызовы функций
509 тыс. / 500 тыс. Все функции отвечают 402, сервис стоит до 22.10 (issue #915). Вместо апгрейда
до Pro ($25/мес) предложен переезд на свой VPS.

Владелец, дословно:

> «если и платить за сервер, то тогда уже за свой собственный.
> Сейчас самое критичное это понять можем ли мы выгрузить базу. проверяй, и делай дамп на муспельхейм»

## Решение

- План Pro в Supabase не покупаем; Swarm переезжает на свой сервер (self-hosted стек Supabase).
- Первый шаг — выгрузка прод-базы и её копия на MUSPELHEIM: шифрованный дамп через
  `.github/workflows/prod-dump.yml` (ветка `ops/prod-dump`), расшифровка локально.
