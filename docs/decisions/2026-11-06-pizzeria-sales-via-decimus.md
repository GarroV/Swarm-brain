# Выручка пиццерий в «Моих странах» — через Децимус

Решение владельца 06.11.2026. Вопрос: «а че с выручкой по пиццериям?» Ответ: «через децимус давай настроим, у него же есть доступ».

**Контекст.** В «Моих странах» колонка «Продажи» была только у страны (выручка с 1-го числа из публичного API Dodo, `_shared/market/mtd.ts`); у раскрытой пиццерии ячейка пустая. Публичный API Dodo выручки пиццерии за месяц не даёт. Децимус раз в сутки собирает её из Dodo IS в `dodois.unit_sales_month`.

**Решение.**
- Источник — Децимус: метод `GET /api/v1/sales` (его решение D713). Свой сбор Dodo IS в Swarm не заводим.
- Ячейка пиццерии — выручка с 1-го числа текущего месяца в евро или «—». Никаких оценок и подстановок: нет данных — «—» (владелец жёстко против подмены данных).
- Строка страны: у страны с данными Децимуса — сумма её пиццерий (строка сходится с пиццериями под ней), иначе публичный API Dodo, как было.
- Подсказка заголовка колонки называет источник и время загрузки.
- Новых секретов нет: тот же `DECIMUS_API_URL` / `DECIMUS_API_TOKEN`; право `sales:month` выдала токену Swarm миграция Децимуса.

**Порядок раскатки.** Сначала Децимус (миграция `0121` и код), потом Swarm. Swarm раньше Децимуса безвреден: метод ответит 403/404, `unit_sales = null`, всё как до изменения.
