# Компактная главная с дневным графиком

Дата: 26.11.2026. Уточнение выбранного владельцем макета после production-просмотра.

- Вернуть линейный дневной график вместо полос сравнения итогов. Данные берутся
  из дневных наблюдений Decimus, месячный итог не распределяется по дням.
- Не соединять пропущенные дни. Подтверждённый ноль остаётся точкой; неизвестное
  значение — разрывом. Разные валюты на одном графике не сравниваются.
- Сократить высоту центрального блока, карточек стран и метрик, уменьшить отступы.
  На узком десктопе график остаётся рядом со сводным числом.
- Заменить большие рейтинговые панели и подробности выездных проверок короткими
  карточками РС, РКО и последней проверки с периодом и переходом в Decimus.
  Подробные списки и просмотр нарушений на основной главной не показывать.
- Сохранить встречи, задачи, напоминания, настройку стран и операционные данные
  пиццерий. Новая компоновка не меняет их API и права доступа.

Разрешён немедленный выпуск этого уточнения в рамках текущего согласованного
обновления главной. Серверный дневной ряд выпускается перед вебом. Миграций нет.
