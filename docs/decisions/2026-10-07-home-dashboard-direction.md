# Главная: рабочий экран + пульс по своей подборке стран

**Дата:** 2026-10-07. **Статус:** направление принято; перенесено в код главной веткой `feat/home-widgets` (РС и РКО — пока образец данных).

- «не забывай что страны есть разные, и нужно явно дать возмонжость выбирать свою подборку. условно, мне нужны болгария, хорватия, словения и сербия. соответственно толкьо по ним я и хочу видеть апдейты по рейтингам, отзывам, РКО и РС и всему остальному»
- «слайдер со стикерами нравится. его точно оставляем»
- «давай ещзе сейча ссделаем акцент на РС и РКО, потому что поинтер пока не подулючен»
- «а может доабвим кастомизацию? для каждого пользователя» / «чтоб была возможность собирать главную страницу из виджетов»

- Доска объявлений: «объявления там должны быть в виде плашек/стикеров ЗАПОЛНИ ОКР, ЗАПОЛНИ ДАЙДЖЕСТ и так далее»

## Что из этого следует

1. Наверху главной — **созвоны дня** и **топ-5 ближайших задач**. Это рабочее ядро экрана, аналитика идёт ниже.
2. **Доска со стикерами (горизонтальный слайдер) остаётся.** Стикеры двух видов: задания, которые ставит система (OKR, дайджест, вычитка, чекпоинт спринта), и объявления админа со сроком.
3. **Пока Pointer не подключён, акцент главной — РС и РКО:** крупные блоки по ним и разбивка по пиццериям подборки; карты и отзывы — компактная заглушка «после подключения Pointer».
4. **Подборка стран — явная и своя у каждого.** Вся аналитика на главной (рейтинги на картах, отзывы, РКО, РС, собираемость, нарушения, продажи) считается только по подборке. Сравнение с остальным IMF доступно, но не по умолчанию. Хранить подборку предлагается в профиле — те же рынки, что задают охват персонального дайджеста (`user_profiles.markets`), чтобы у человека не было двух разных «моих стран».
5. **Главная собирается из виджетов, раскладка своя у каждого.** Режим «Настроить главную»: перетащить, скрыть, ширина «½ / вся строка», «+ Добавить виджет» из каталога, сброс к раскладке по умолчанию. Раскладка хранится в профиле пользователя рядом с подборкой стран. По умолчанию: созвоны и задачи, доска, РС и РКО, пиццерии, «Куда смотреть» и страны, нарушения, карты. Продажи — в каталоге.

## Источники данных главной

- Рейтинги и отзывы на картах — Pointer API (ключ ещё не выдан).
- РС (стандарты, полумесячные волны) и РКО (клиентский опыт, недели) — Google-таблицы «Аналитика IMF» и «Аналитика IMF (РКО)», лист «Качество по пиццериям»: выгрузка CSV → загрузка в Swarm инструментом MCP (см. решение 08.10 ниже).
- Продажи — публичный API Dodo, уже собирается для «Анализа рынка».

## 08.10.2026 — РС и РКО: настоящие данные из таблиц, а не образец

Владелец: «СР и РКО у тебя есть таблицы, давай не выебывайся. состукуйся с децимусом, мы там прорабатывали этот же вопрос».

- Источник — лист «Качество по пиццериям» таблиц «Аналитика IMF» (РС) и «Аналитика IMF (РКО)»: баллы каждой пиццерии по волнам и неделям. Разбор листа перенесён из Децимуса (`src/ratings/sheet.py`, ветка `feat/ratings`, решения D317–D334 там же).
- Загрузка — выгрузка листа в CSV и инструмент MCP `quality_import` (по образцу `market_*`: данные вносятся через MCP, а не файлами в репозиторий). Баллы живут в базе, в публичный репозиторий не попадают.
- Средний балл страны — среднее по её пиццериям (как D333 Децимуса).
- Собираемость и топ-нарушения пока остаются образцом с пометкой «пример»: они на других листах тех же таблиц, подключаются следующим шагом.
