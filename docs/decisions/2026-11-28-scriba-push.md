# Внутренние сигналы вместо опроса Scriba

Дата:28.11.2026. Основание: GarroV/backlog#2416, связанная задача#2415.

Swarm сообщает о работе сам. Бот не опрашивает приглашения и календари.
Состояние доставки хранится в базе: повтор с нарастающей паузой продолжается
до подтверждения либо истечения срока задания. Подтверждение означает устойчивый
результат обработки, а не получение HTTP-запроса в память процесса.

Сигнал содержит только вид задания и id. Listener оркестратора доступен внутри
Docker-сети, без опубликованного порта; запрос требует общего секрета.
Ссылку и прежний grant бот получает существующим авторизованным путём.
Повтор своего неподтверждённого запуска возобновим, другой агент не получает
ту же строку. Имя контейнера связано с id задания; подтверждённый запуск,
штатный отказ или уже выполненная заявка терминальны.

Google Calendar использует events.watch с существующим calendar.events.readonly.
Webhook проверяет канал, секрет канала и ресурс, затем сохраняет dirty-маркер.
Обновление плана, продление и остановка каналов выполняются внутренним worker.
Планирование будущих встреч использует прежнюю общую политику accepted,
платформ, организатора и комнаты. Перенос/удаление/выключение отменяют pending
задания. Периодическое обновление горизонта и продление канала не являются
опросом со стороны бота. Пропуски и проверка прибытия сохраняются.

Все вызовы бота к API идут через внутренний Envoy VPS, с прежней авторизацией.
Изолированные контейнеры встреч получают этот путь через существующий egress
proxy; доступ к остальной сети не расширяется.

Новые OAuth-права, обход подтверждения домена и изменение Workspace-политик
в задачу не входят. При таком требовании Google выпуск останавливается.
Миграции, секреты и выпуск кода требуют согласованного порядка. Production
обновляется только по отдельному разрешению владельца в ночное окно.

Источники: [Google push](https://developers.google.com/workspace/calendar/api/guides/push),
[events.watch и scopes](https://developers.google.com/workspace/calendar/api/v3/reference/events/watch).
