# Напоминания по задачам — не ночью, с 9:00 по Москве

**Дата:** 13.10.2026 · **Кто решил:** владелец · **Где:** разговор в Claude Code

## Решение (дословно)

«Бот присылает уведомления о просроченных задачах… и он присылает по ночам. Зачем? Давай поставим время отправки таких напоминаний на, не знаю, утро 9 часов, допустим… Давай по Москве пофиг возьмем, если это важно.»

## Что это значит

Пинг задачи (ручная дата напоминания) уходит не раньше 9:00 по Москве. Наступившее с полуночи ждёт первого утреннего тика крона (раз в час). Пинг, наступивший днём, уходит как раньше — ближайшим тиком. Текст и получатели не меняются, меняется только время.

Правило — `pingSendingOpen` в `supabase/functions/swarm-bot/handlers/task-pings.ts`.

## Почему

Крон раз в час, дата напоминания наступает в полночь по Белграду, поэтому пинги уходили ровно в 00:00: за две недели до 13.10 — 59 из 62 ночных `task_reminder`.
