# 2026-10-07 — план пространства спринтов вместо бэклога; «+ задача» в группе; флажок «Мои задачи»

**Повод.** Набор спринта из шторки «Взять из бэклога» (плоский список задач пространства проектов) владельцу неудобен. Нужно видеть весь план большого проекта («Инициативы качества») сразу: все инициативы, все задачи, что сделано и что нет.

## Решения владельца (07.10.2026, дословно)

- «то, как реализовано сейчас, добавление задач из проектов, это неудобно, это не подходит … это нужно пересматривать 100%».
- «бэклок - видимо, есть смысл убрать, потому что бэклок у нас появляется в виде конкретного большого списка задач с разделами, ну то есть, группами задач … У нас остается та же самая структура, что и в проектах. То есть есть проект, есть его подпроекты, есть задачи в проектах. Просто здесь появляется некий другой элемент на доске, который видно, в котором видно весь список задач».
- «при добавлении в самом спринте задача также появляется и в этом проекте».
- Набор спринта — «перетягиванием из общего дерева … на доску уже, конкретно идущего спринта».
- В группе спринта — «небольшой плюсик, типа добавить задачу … лаконично, адекватно, спокойно, красиво».
- «чекбокс Мои задачи … при включении этого чекбокса … вверху списка показываются только задачи того человека, который сейчас зашел … при отключенном чекбоксе этого нет».
- «предложи дизайн свой … запусти стенд на муспльхейм, и покажи … Все, что по пути у тебя будут возникать вопросы. Делай так, как ты считаешь нужным».

## Что из этого следует

- Опирается на решение 05.10 ([группы = подпроекты проекта пространства](2026-10-05-sprint-groups-are-subprojects.md), issue #811): дерево плана — это проект пространства → его подпроекты (инициативы) → задачи.
- Шторка «Взять из бэклога» снимается, её место занимает панель «План».
- Раздел «Проекты» защищён; правки по этой просьбе владельца идут с трейлером `Owner-approved`.

## Как сделано (выборы исполнителя по «делай так, как ты считаешь нужным»; правки — после просмотра стенда)

- **План = группы задач пространства** (`sprint_group`, `sprint_id` = пространство) и их задачи. Перевод групп в настоящие подпроекты проекта пространства на доске «Проекты» (#811) — отдельный шаг: для плана он не нужен, а раздел «Проекты» защищён. Сервер и база не менялись.
- **Компьютер:** «План» — колонка 320–360px слева от состава, кнопка «План» в полосе спринта прячет/показывает её, выбор помнится. **Телефон:** шторка поверх экрана, задачу берут кнопкой «→» (перетаскивания на таче нет).
- В плане видно всё: открытые выше закрытых, сделанные зачёркнуты, отменённые помечены, «в спринте» — пометкой; итог «X из Y» сверху, поиск, «Скрыть готовые».
- Бросок — на любое место списка или канбана: группа задачи берётся из её проекта, целиться не нужно.
- «+» у группы СПРИНТА — задача в группу и в спринт; «+» у группы ПЛАНА — только в план (план шире спринта). Оба открывают стандартную карточку (решение 19.09.2026).
- «+» больше не прячется за режимом правки: набор состава — ежедневное действие.
- «Мои задачи» — по `assignee_telegram_ids` живой задачи: блоки «Мои задачи» и «Остальные», в обеих группировках.
