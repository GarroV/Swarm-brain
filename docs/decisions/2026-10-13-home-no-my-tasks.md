# Главная: виджет «Мои задачи» не нужен

**Дата:** 13.10.2026

**Решение владельца (дословно):** «стоп, на главной мои задачи не надо».

**Контекст.** Предлагалось свести «Просрочено» и «Сегодня» в одну секцию «Задачи сегодня» в виджете
«Мои задачи» на главной (PR #948) и поставить этот виджет в раскладку по умолчанию. Виджет в раскладку
по умолчанию не входит с 07.10.2026; задачи на главной показывает «Ближайшие задачи» (`top5`).

**Что из этого следует.**
- «Мои задачи» (`myTasks`) в раскладку по умолчанию не ставим и не дорабатываем; PR #948 закрыт.
- Виджет остаётся в каталоге «Настроить главную» как есть — убирать его владелец не просил.
- Сведение «Просрочено» → «Задачи сегодня» на экране «Задачи» (уже в проде) не затронуто.
