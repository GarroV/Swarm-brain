# Таблица задач: колонки тянутся и переставляются; карточка задачи — настройки чипами

**Дата:** 28.09.2026 · **Кто решил:** владелец · **Где:** разговор о макете списка и карточки задачи
(макет `Main.dc.html` / `Drawer.dc.html`), передано через координирующую сессию

## Решение (дословно)

1. На макет: «визуал да, ебаш».
2. «значки не трогаем» — значки срока/пинга/повтора/людей/рынка в строке таблицы остаются как есть.
3. «я взял в учет что можно колонки будет сдвигать, не пропусти это».
4. «давай сделаем перетаскивание» — перестановка колонок перетаскиванием за шапку.

## Что это значит

**Таблица «Задачи» (десктоп):**

- «Задача» забирает освободившееся место, название — до двух строк, дальше многоточие, целиком — в
  подсказке. «Проект» и «Списки» вдвое уже прежнего, длинное режется многоточием; в «Списках» —
  первый список и «· +N».
- Ширину колонок «Задача», «Проект», «Исполнитель», «Списки» тянут мышью за правый край ячейки
  шапки (двойной клик по ручке — ширина по умолчанию). Порядок всех колонок, кроме «Задачи»,
  меняется перетаскиванием за середину ячейки шапки; колонка значков переезжает целиком.
- Раскладка помнится на человека в `localStorage` (без хранилища — дефолт); кнопка «Сбросить
  колонки» в панели фильтров появляется, только когда раскладка отличается от дефолта.

**Карточка задачи (панель справа и окно на телефоне — один `TaskModal`):** название → все
настройки чипами под ним (статус — сегмент из трёх, затем срок, пинг, повтор, проект, страна,
исполнитель; пустое — пунктирный чип с названием свойства) → Списки → Ссылки → Описание →
Подзадачи → Комментарии. Логика выбора у свойств прежняя, поменялась только оболочка.

## Чего это не касается

- Мобильных экранов `TaskDetail` (открывается из пуша о комментарии) и `NewTask` (свайп «Изменить»
  и «+» на телефоне) — это отдельные старые формы, они не переделывались.
- Раздела «Проекты» (защищённый) — его файлы не тронуты; карточка задачи, открытая с доски, та же.
