# Тезисы для любой связной речи, а не только для деловой

Дата: 2026-10-17.

Первая живая запись офлайн-встречи из браузера (монолог владельца, 56 с) получила вместо тезисов плашку «В записи нет содержательного обсуждения». Владелец, дословно: «там был записан монолог. какая нахуй тебе разница деловая тема или нет?»

Причина: правило `НЕТ_ТЕЗИСОВ` в `TEZIS_SYSTEM` (`_shared/meeting-processor.ts`) перечисляло примеры содержания «работа, планы, проблемы, договорённости», и модель читала их как «только деловое».

Решение: тема записи значения не имеет. Любая связная речь — монолог или разговор, рабочий или нет — получает тезисы. `НЕТ_ТЕЗИСОВ` — только для реально пустой записи: тест микрофона, тишина, бессвязные обрывки.

Проверено сухим прогоном (тот же промпт и модель, что прод, без записи в базу): стенограмма этой записи — старый промпт 3/3 отказа, новый 3/3 тезисов; пустая «проверка микрофона» — новый промпт 3/3 отказа; `scripts/tezisy-injection-dryrun.ts` — зелёный.
