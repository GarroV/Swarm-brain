# Ночной выпуск рекордера 42

Дата: 26.11.2026. Владелец разрешил ночную раскатку подготовленной части рекордера.

Окно: 26.11.2026 23:00 — 27.11.2026 06:59 Europe/Belgrade.
Состав: сообщения и выбор встречи внутри блокнота, вопросы о Скрибе в текущей
поверхности записи, сворачивание блокнота в видимую пилюлю при потере фокуса.
Доказательства: сборка и 17 целевых проверок из
[состояния работы](../reference/2026-11-26-recorder-progress.md).

Разрешение включает слияние PR этой ветки, выпуск архива recorder-build-42,
загрузку архива штатным CI и последующее переключение номера и контрольной
суммы раздачи через PR и штатную раскатку функций в том же ночном окне.
Повторное разрешение на перечисленные действия не требуется.

Полное объединение доски с рекордером и запуск записи после фактического входа
в комнату в этот выпуск не входят. Работающий рекордер не перезапускается вручную;
автообновление использует существующий запрет обновления во время записи.
