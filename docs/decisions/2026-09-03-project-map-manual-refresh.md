# «Карта проекта» обновляется руками раз в пару месяцев — автоматизации не будет

**Дата:** 2026-09-03 · **Статус:** принято, действует · **Решение владельца, не техническая деталь**

> ⛔ Не менять без явного решения владельца. Закрывает развилку из
> [#62](https://github.com/GarroV/Swarm-brain/issues/62) («как держать карту живой»).

## Повод

Карта — статический `miniapp/public/system-map.html` (54 КБ, 619 строк, **35 узлов вшиты в HTML**),
открывается чипом «Карта проекта» в шапке дашборда. Сверка 03.09.2026 показала: содержание не
менялось с 28.06.2026 (`95d80cf`), то есть карта отстала примерно на девять недель фич — врёт по трём
узлам и не знает мобильной вёрстки, уведомлений, регулярных задач, «Встреч сегодня», Google-входа,
bumblebee и MCP-возможностей.

Развилка была из трёх вариантов: (а) собирать узлы из одного источника, чтобы карта не расходилась
сама; (б) внести карту в Definition of Done рядом с доками — тронул поверхность, проверь карту;
(в) признать, что статическая карта не оправдывает поддержки, и снять чип.

## Решение

Владелец, дословно:

> «я думаю в ручном режиме раз в пару месяцев. не уверен что надо тратить ресурс на регулярное пополненеи»

**Карта остаётся, но живёт ручной ревизией раз в ~2 месяца.** Ни генерации из источника, ни правила
в DoD — цена поддержки выше пользы от свежести.

## Что это значит на практике

- **Карта НЕ входит в Definition of Done.** Добавил экран, вкладку, кнопку — карту править **не
  обязан** и правило «проверь карту» не заводим. Это единственное исключение из блокирующего набора
  доков: `ARCHITECTURE.md`/`QUICK_REF.md` по-прежнему обновляются тем же коммитом, что и код.
- **Генерацию узлов из одного источника не делаем.** Отклонено как трата ресурса, а не отложено «на
  потом»: не переоткрывать без нового решения владельца.
- **Ревизия — целым заходом раз в ~2 месяца**, отдельной задачей ([#62](https://github.com/GarroV/Swarm-brain/issues/62)),
  а не по чуть-чуть. Первый ручной проход после этого решения — по накопившемуся отставанию;
  следующий ориентир — начало ноября 2026.
- **Чип с дашборда не снимаем** — карта нужна как обзор для новых людей.
- **Следствие, с которым живём осознанно:** между ревизиями карта отстаёт до двух месяцев. Значит она
  **обзорный артефакт, а не источник истины**: сверять систему по ней нельзя, канон — `ARCHITECTURE.md`
  и код. По этой же причине на самой карте уместна дата последней сверки, чтобы читатель видел
  давность и не принимал её за текущее состояние.
