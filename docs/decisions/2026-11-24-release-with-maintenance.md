# Выпуск через заморозку

Дата: 24.11.2026.

Владелец разрешил выпуск подготовленного пакета в прод через заморозку в текущем сеансе.
Пакет включает вход в Meet с рабочей почтой, доработки рекордера и scriba, связанную
миграцию и диагностику. Для этого выпуска допускается дневная раскатка с заморозкой.

Перед изменениями проверяются отсутствие записи и обработки, состав миграций и исходник.
Заморозка ограничена сроком и снимается после проверки рабочих маршрутов. Активную запись
не прерывать. Штатное ночное окно для остальных выпусков сохраняется.
