# 06.11.2026 — бот приходит ровно ко времени начала и повторяет заход при сбое

**Решение владельца (дословно):** «проверьь чтобы он нормально ходил, чтоб была вторая попытка. При этом не надо рпиходить за 2 минуты. никто не приходит так. сделай чтобы приходил ровно во время».

**Повод.** 06.11 бот вышел на встречу в Meet в 14:58 (за 2 минуты, `autojoin.leadMs = 2 мин` — значение поставлено при сборке бота, владельца не спрашивали), страница Meet не загрузилась за 60 с → `join_failed`, повторной попытки нет, встреча пропущена целиком. Ранее владелец уже жаловался: «до встречи ещё две минуты, зачем бот уже долбится».

**Что делаем.**
- Автозапуск по календарю: бот не выходит раньше начала события (`leadMs = 0`); заходит в первую минуту встречи.
- Сбой загрузки страницы звонка (таймаут навигации, сетевая ошибка) — повторная попытка захода, а не отказ с первого раза. Отказ по существу (не впустили, гостевой доступ закрыт, вход слетел) — без повтора, как раньше. Уведомление об отказе — только после последней попытки.

**Не меняется.** Ожидание у двери (5 мин) — владелец не просил менять.
