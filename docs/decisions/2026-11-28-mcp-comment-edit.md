# Редактирование собственного комментария из MCP

MCP поддерживает `edit_task_comment`: автор может заменить полный текст своего
комментария к доступной задаче. Автор берётся из проверенного токена; аргумент
с чужой личностью отклоняется общей дверью MCP. Воркспейс и видимость задачи
проверяются до записи. UPDATE ограничен одновременно задачей, комментарием
и автором; административного обхода редактирования нет.

Пустой текст и превышение существующего предела комментария отклоняются общим
валидатором. Автор и первоначальное время создания не меняются. Первоначальные
уведомления не рассылаются заново. Отдельного инструмента правки от имени другого
автора нет.

Существующий `delete_task_comment` сохраняет двухшаговое подтверждение через
`confirm.ts` и прежнюю проверку автора. Редактирование — idempotent write,
удаление — destructive. Повторная реализация удаления не вводится.
