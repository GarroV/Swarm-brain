# Доска проектов — общее пространство, приватность наследуется вниз

**Дата:** 2026-08-24 · **Статус:** принято, действует · **Решение владельца, не техническая деталь**

> ⛔ **Не менять без явного решения владельца.** Это правило уже переписывалось трижды (2026-08-07 → 08-19 → 08-24). Если код кажется дырой — сначала читать этот файл, потом спрашивать, и только потом трогать.

## Повод

Владелец показал два экрана одной доски: у себя — «Vibe Coding 21» с подпроектами (P&L 12, Swarm Brain 5), у начальника — та же доска как «Vibe Coding 4», без единого подпроекта и с пустыми колонками. Причина (issue #86): приватным считался **любой** подпроект (`parent_id ≠ null`, правило 2026-08-07/08-19), поэтому рабочие подпроекты по сотрудникам («Дмитрий Карпов» — 11 задач, «Ксения Федотова» — 7) не видел никто, кроме автора, а флаг `is_private` на подпроекте не работал вовсе — тумблера-глаза у подпроекта не было.

## Решение (формулировки владельца дословно)

> «проекты и подпроекты это общее пространство для всех»

> «про глаз я помню, но ты его так и не нарисовал нормально. и это нормальный функционал, но растяни его на подпроекты тоже. если проект открыт значит и подпроекты открыты. и наоборот. если проект закрыт значит и подпроекты закрыты. или я могу захотеть закрыть один из подпроектов, значит тогда он скрывается ото всех»

Из этого:

| Ситуация | Кто видит |
|---|---|
| Проект открыт, подпроект открыт | вся команда воркспейса |
| Проект **закрыт** глазом | только автор проекта — **вместе со всеми его подпроектами** |
| Проект открыт, **подпроект закрыт** глазом | подпроект — только его автор; группа и соседние подпроекты остаются общими |
| Строка без `created_by` (легаси/системная) | все — «ничейное» не прячем |

Админского обхода нет: закрытая строка закрыта и для админа — это продолжение решения [2026-08-21](2026-08-21-admin-visibility.md) (оверсайт руководителя есть у ЗАДАЧ, у проектов нет).

## Что это значит для кода

- Предикат — `canViewProject(row, viewerId, index)` в `_shared/tasks/project-access.ts`; `index` = `parentLookup(всеСтрокиВоркспейса)`. Обход идёт вверх по `parent_id`: закрытая строка на любом уровне цепочки рубит доступ всем, кроме своего автора.
- **Родителя нет в индексе → строка НЕ видна** (fail-closed). Показать лишнее хуже, чем не показать; тот же принцип, что при отсутствии личности зрителя.
- Подпроект внутри чужой закрытой группы закрыт даже для того, кто создал сам подпроект: закрыта вся ветка.
- Мутация = просмотр (один предикат): открытую строку правит любой участник (решение 2026-07-01), закрытую — только автор.
- UI (`SprintBoard.tsx` → `PrivacyToggle`): тумблер есть и у проекта, и у подпроекта; закрытое состояние подписано словом «Только я»/«Only me», а не голой пиктограммой — по прямому замечанию владельца, что иконку «так и не нарисовал нормально». У подпроекта закрытой группы вместо кнопки — метка «Закрыт вместе с проектом»: нажатие там ничего бы не изменило.

## Последствия

- Данные не мигрировались и не требовали миграции: все 12 подпроектов прода уже имели `is_private=false`, то есть после раскатки просто стали видны команде — что и есть решение владельца.
- Прежнее обоснование «чтобы Анна видела не все подпроекты, а только свои» (2026-08-19) **отменено**: скрывать нужное теперь можно точечно тумблером, а по умолчанию доска общая.
