**Дата:** 2026-08-24 · **Статус:** принято, действует · **Решение владельца, не техническая деталь**

| Вопрос | Ответ владельца (24.08.2026) |

| Когда заливаем | **«Утро обычное, ночь для тяжёлого»** — обычные правки в окно 09:00–10:00 будни (Белград), миграции БД и рискованное — ночью |

| Разрешение | Раскатка идёт **только по явному «да» владельца** в том же разговоре и на конкретный пакет |

## Что считается раскаткой (всё под разрешением)

- `supabase functions deploy` любой edge-функции;
- **пуш или мёрж в `main`** — Cloudflare Pages собирает веб с `main` автоматически, то есть обычный пуш уже раскатывает интерфейс;
- миграции на прод-базе и правка прод-данных;
- смена секретов, расписания pg_cron, `LATEST_BUILD` рекордера.

Зелёные тесты, готовый код и «я уже проверил» разрешением **не являются**. «Да» на прошлую раскатку не переносится на следующую.

## Что НЕ ограничено

Дневная работа не встаёт: код пишется, коммитится и пушится в рабочую ветку свободно. Задерживается только последний шаг. Если правка трогает `miniapp/`, дневная работа живёт в ветке и вливается в `main` в окно — иначе веб уедет раньше времени.

Живой баг, который бьёт по людям прямо сейчас, окно обгоняет — но по-прежнему требует явного «да» владельца.

## Механика

```bash
make deploy-plan     # что готово, но не раскатано: функции, веб, миграции, рекордер
make deploy          # раскатать (вне окна откажет; FORCE=1 — осознанный обход)
```

Скрипт — `scripts/deploy-window.sh`. Состояние прода помечено git-меткой `prod-deployed`: она двигается только после успешной раскатки, поэтому «что накопилось» считается от неё, а не от памяти. Правка в `_shared/` тянет в список всех потребителей модуля — иначе на проде окажется функция со старой копией общего кода.

Окно зашито в скрипт: будни 09:00–09:59 Европа/Белград. Выходные и остальные часы — отказ с подсказкой про `FORCE=1`.

## С 1 сентября

Квота GitHub Actions заморожена до 01.09.2026 (решение владельца не платить за минуты). После возврата квоты — перенести `deploy-window.sh go` в scheduled workflow на то же окно, из ветки, куда льётся одобренное. До тех пор заливка ручная.
