# 2026-10-08 — срочное предупреждение владельцу о тишине в записи бота

**Повод.** 08.10.2026 бот встреч просидел в звонке Контур.Толка 57 минут и записал цифровую тишину
(#861): часть TURN-серверов Толка по TLS не пропускает медиа. Встреча ушла с исходом `recorded`, ИИ
написал «нет содержательного обсуждения», и узнали об этом только от коллеги.

**Решение владельца** (дословно): «Давай тогда настроим срочное уведомление через бота фордж».
На предложенные текст, адресата и условие — «Да, так».

- **Адресат:** только владелец, через бота канала FURCA.
- **Условие:** бот в звонке, кроме него есть люди, 3 минуты подряд цифровая тишина; одно сообщение
  на встречу плюс одно «звук вернулся», если вернётся.
- **Текст:** `⚠️ Scriba: в звонке «<название>» (Толк/Meet) 3 мин нет звука, запись сейчас пишет
  тишину. Запуск <id>.` / `✅ Scriba: звук в «<название>» вернулся.`

Менять текст, адресата или условие — только с новым «да» владельца (глобальное правило «никакой
коммуникации без владельца»). Реализация — `bot/src/orchestrator/audio-watch.ts`, `owner-alert.ts`;
описание — ARCHITECTURE §Бот scriba → «Сторож тишины».

**Там же, 08.10.2026 — имя бота.** Владелец: «стандартное название есть название бота скриба, есть
нот-текер, чтобы было понятно, что это такое и зачем оно пришло и чем оно занимается». Гостевое имя
в Толке — «Scriba Notetaker», как в Meet (PR #863).

**Открыто:** резервный запуск рекордера человека, когда бот не слышит звонок, — владелец спросил «есть
шанс?»; ответ — да, отдельной задачей (текст капсулы рекордера тоже потребует его «да»).
