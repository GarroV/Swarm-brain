подготовленного нового визуала главной. Это разовое дневное исключение
для данного пакета; общее ночное окно сохраняется.

не включаются. Работающие записи и обработка не прерываются.

функции Swarm — из 5307a752 штатным шлюзом. Аддитивные таблицы 0135 не удалять;
добавленное право интеграции можно отозвать отдельно.
