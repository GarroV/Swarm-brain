## Что это значит

- Встреча 1-1 «в личное» — ОДНА запись, а не две копии: владелец (`owner_id`) — опубликовавший, второй участник — в `entries.shared_with`. Видят только они двое; второй участник читает, правит и спрашивает по встрече; удалить и сменить видимость может только владелец. Модель «одна запись» выбрана в разговоре 30.09 (правка одним видна другому, дедуп и задачи не раздваиваются).
- 1-1 = ровно два владельца черновика-человека и не больше двух людей в календаре. Отрицательный id — живой веб-пользователь без Telegram, он считается человеком.
- Раскатку делает координатор в ночное окно; миграция — до функций.
- «Спросить по встрече» для второго участника держится на том же правиле видимости записи (`canViewEntry`), отдельной проверки нет.
- `search_entries_by_country` не удаляется, а получает параметры воркспейса и пользователя с тем же фильтром видимости; прежняя сигнатура без них снята, вызов — только у `service_role`.
