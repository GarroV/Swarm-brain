# Укрепление проверок доступа к проектам — правка защищённого раздела разрешена

**Дата:** 16.10.2026

**Вопрос владельцу:** «Swarm: две дыры сидят в разделе „Проекты“, а он защищён, и правки туда идут только по вашей прямой просьбе. Первая: задачу можно привязать к чужому закрытому проекту. Вторая: закрытость проекта не прячет его задачи, и закрыть чужой проект может любой участник. Чинить их в „Проектах“?»

**Решение владельца (дословно):** «Да, чини»

**Что закреплено:**
- Привязка задачи к проекту проверяет видимость проекта вызывающему, а не только принадлежность воркспейсу.
- Задачи закрытого проекта видят только те, кто видит сам проект.
- Закрывать и открывать проект (тумблер приватности) могут только автор проекта и админ.

**Почему:** раздел «Проекты» защищён (`.github/protected-paths.txt`), правка в нём идёт только по прямой просьбе владельца. Эта запись — ответ на вопрос «кто разрешил», коммиты несут трейлер `Owner-approved`.
