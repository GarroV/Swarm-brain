# Оставшиеся задачи Swarm Brain

Дата: 26.11.2026.

- Завершение разработки означает исправленный код, необходимые проверки и готовый
  к рассмотрению pull request. Это не поручение автоматически сливать или раскатывать
  изменения. Раскатка и заморозка требуют отдельных разрешений согласно
  [уточнению](2026-11-26-explicit-approval-for-freeze.md).

- Продолжить согласованные оставшиеся исправления рекордера и scriba по фактическому
  состоянию кода, опубликованных сборок и журналов. Уже выполненное повторно не реализовывать.
- Проверка подстраховки требует участия владельца: допуск бота в звонок, получение
  сигнала о тишине, ручной запуск рекордера, проверка сохранённой записи после остановки.
  Успешная штатная запись бота сама по себе подстраховку не подтверждает.
- Текущий экран страны рекордера разрешено распространять на команду. Он уже входит
  в публично предлагаемую сборку 41; отдельного ограничения на владельца в коде нет.
- Разобрать приватные рабочие заметки Swarm-brain и Decimus; репозитории оставить
  публичными. Прежнее решение не переписывать опубликованную Git-историю сохраняется.
- Остальные решения по бэклогу отложены.
- К задаче смены транскрибации вернуться 20.01.2027. До этого модель не менять.
