# Каждая запись в базе помечена автором

**Дата:** 03.10.2026 · **Кто решил:** владелец · **Где:** разбор снимков недельного отчёта (`claude-weekly-tracker`)

## Решение (дословно)

«что блять значит не записывает? все данные в базе должны быть помечены!»

## Что это значит

- Любая запись, которую создаёт человек (сам или через своего Claude/бота/рекордер), хранит, **кто** её создал. Канал (`added_by = "claude_desktop"` и т.п.) автором не считается.
- Личность берётся из токена вызывающего, а не из аргументов.
- Новая дорога записи без автора — дефект, а не допустимое состояние.

## Почему

Восемь записей недельного отчёта (18–28.09) лежали в общей базе без автора: `add_knowledge` и `upload_file` в `swarm-mcp` ставили `owner_id = null` для общих записей, хотя личность известна из токена. Установить, кто их сохранил, оказалось невозможно — только косвенно, по совпадению времени. Задача #790.
