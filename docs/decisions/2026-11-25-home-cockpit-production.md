# Рабочая главная: пульт страны

Дата: 2026-11-25. Выбранная компоновка становится главной по умолчанию.
Сверху располагаются компактные напоминания и объявления; справа вверху —
ближайшие встречи с действующей кнопкой подключения и ближайшие задачи.
Слева — карточки стран с выручкой, выбранный показатель с графиком,
шесть компактных переключателей метрик, рейтинги, проверки и пиццерии.

Кнопка «Настроить главную» открывает окно выбора 1–8 стран из полного
справочника и блоков рабочего дня. Изменения до сохранения остаются черновиком;
ошибка сохранения не выдаётся за успех. Подборка стран сохраняется в профиле,
блоки — на устройстве с привязкой к пользователю. Прежняя пользовательская
раскладка остаётся доступной отдельно, без удаления её настроек.

Периоды показываются датами: например, `01–14.11.2026 vs 01–14.10.2026`.
Видимые переключатели называются «Прошлый месяц» и «Прошлый год»; сокращения
MTD, MoM и YoY не требуются для понимания экрана. Даты берутся из ответа источника,
а не из предположения браузера о часовом поясе страны.

Данные идут из оконного кеша Decimus через аутентифицированный прокси Swarm.
До появления подтверждённых дневных рядов большой график сравнивает значения
двух указанных периодов столбцами. Дневная линия из макета не синтезируется.
Неподтверждённый период для сопоставимых пиццерий не показывается процентом.
Пропуски, частичные данные, устаревание и смена валюты сохраняют ограничения
контракта; демонстрационные цифры не переносятся в рабочий интерфейс.

Владелец разрешил прод-раскатку пакета в этом разговоре. Выпуск выполняется
в штатное ночное окно: сначала Decimus со схемой, сбором данных и правом чтения
интеграции Swarm, затем серверный прокси и рабочая главная Swarm.
