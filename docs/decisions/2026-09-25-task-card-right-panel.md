# Карточка задачи везде открывается панелью справа

**Дата:** 25.09.2026 · **Кто решил:** владелец · **Где:** разговор о витрине `feat/new-ui` (PR #496), issue #528

## Решение (дословно)

1. «договаривались что визуал работы с задачами будет везде один: спрвава должно выходить окно для взаимодействия».
2. «ну корч проследи чтоб механика везде была единая».

## Что это значит

- На десктопе (ширина от 720px, та же граница, что у раскладки) любая точка входа в задачу
  открывает одну и ту же **панель справа на всю высоту**: «Задачи», «Спринты», доска, таймлайн,
  проекты, задачи из встречи, главная.
- Решает само окно (`TaskModal`), а не вызывающий экран: флага `drawer` у вызовов больше нет.
  Флаг передавали три точки входа из десяти, и остальные молча открывали окно по центру.
- На мобайле карточка остаётся окном по центру: там у экрана нет места «за панелью».
