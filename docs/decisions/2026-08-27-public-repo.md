# Репозиторий Swarm-brain остаётся публичным

**Дата:** 2026-08-27 · **Статус:** принято, действует · **Решение владельца**

> ⛔ Не переводить репозиторий в приватные и не «исправлять» видимость под глобальное правило.
> Глобальное правило («репозиторий проекта по умолчанию приватный», 20.08.2026) здесь **перекрыто
> осознанным решением владельца по этому проекту.**

## Повод

Сессия обратила внимание на расхождение: `gh repo view` показывает `PUBLIC`, тогда как глобальное
правило требует приватный репозиторий по умолчанию. Владелец 27.08.2026:

> «публичный да, пусть так и будет.»

## Что это значит на практике

- **Видимость не меняем.** Ни в рамках уборки, ни «для соответствия правилу». Отдельно помнить, что
  у публичных репозиториев минуты GitHub Actions бесплатны, а у приватных режутся тарифом — перевод
  в приватные упрёт CI в квоту (она уже кончалась, см. заморозку проверок до 1 сентября).
- **Issues и обсуждения читаются кем угодно.** Задачи формулируем без того, что не должно быть
  публичным: секретов, точных адресов внутренних сервисов, персональных данных команды.
- **Находка по безопасности — НЕ issue.** Публичный репозиторий + незакрытая дыра = приватный
  security advisory (`POST repos/{owner}/{repo}/security-advisories`), а в трекер идёт нейтральная
  строка без рецепта. Затирание тела задачи не помогает: GitHub показывает историю правок публично.
  Куплено ошибкой: рецепт обхода авторизации в живом продукте однажды провисел публично 13 часов.
- **Приватность данных продукта решением не затронута.** Публичен код и трекер, а не база: доступ к
  данным по-прежнему держится на проверках в коде (`checkAllowed`, `visibilityFilter`,
  `entries-guard`) и внешнем замке RLS deny-all.
