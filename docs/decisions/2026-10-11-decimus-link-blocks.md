Контекст: хранение баллов РС/РКО (схема `ratings`) и оценок на картах (схема `maps`, Pointer API) уже живёт в Децимусе; API чтения для Swarm — GarroV/decimus#567, PR #570. Продолжение решения 08.10 в [2026-10-07-home-dashboard-direction.md](2026-10-07-home-dashboard-direction.md).

Порядок:
1. **РС/РКО** — влить API чтения Децимуса (баллы, собираемость, нарушения), выдать сервисный токен, подключить `GET /quality` Swarm к живым данным.
2. **Карты** — маршрут оценок на картах в API Децимуса; Swarm берёт карты оттуда, а не своим ключом Pointer.
3. **Проверки** — выездные проверки Децимуса (`/api/v1/inspections`) забираются в Swarm и становятся рабочими данными (не только показ).
