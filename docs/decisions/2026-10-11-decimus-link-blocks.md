Порядок:

## 11.10.2026 — блок 3: что Swarm делает с проверками

На вопрос «что делать с проверками Децимуса в Swarm» — варианты: виджет на главной, спросить через Claude (MCP), задачи из проверок, нарушения проверки тоже — владелец: «кажется что все инструменты нужны».

Значит, в блок 3 входят все четыре:
1. Виджет на главной — последние проверки по странам подборки (пиццерия, дата, %, класс, движение к прошлой), клик — отчёт в Децимусе.
2. Инструмент MCP Swarm — вопросы о проверках по живым данным Децимуса.
3. Задача в Swarm из проверки — вручную, кнопкой (не автоматически).
4. Нарушения проверки — API Децимуса расширяется, чтобы отдавать не только итог.
