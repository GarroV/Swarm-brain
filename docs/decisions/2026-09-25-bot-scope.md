# Telegram-бот SWARM: только внести и спросить

**Дата:** 25.09.2026 · **Кто решил:** владелец

## Решение
Дословно: «бот сейчас нужен только для быстрого внесения информации и быстрого вопроса. все. никаких задач, исполнителей и ничего прочего он не делает для команды».

## Что из этого следует
- Живая поверхность бота (`swarm-bot`): записать в базу и спросить базу. Её держим рабочей.
- Задачи, исполнители, встречи и прочие флоу бота для команды — не продуктовая поверхность: не развиваем, не проверяем и не чиним по собственной инициативе. Их удаление — отдельное решение владельца.
- Работа команды — в вебе.
- Не путать с ботом звонков scriba: это другой продукт.
