# 07.11.2026 — нынешний вид Swarm и есть визуальный эталон; forma подтягивается к нему

**Решение владельца (дословно):** «доски состарым макетом не уверен. по сути то как сейчас выглядит сворм брейн - уже референс и идеал. тут по сути надо бы форму обновить по канонам сворма.»

**Повод.** Сверка открытых задач визуала 07.11: доска спринтов против исходного артефакта (#394), «кнопки в артефакте приятнее, нужен ребрендинг» (#395, 19.09), редизайн с открытым пунктом «визуальный язык Forma» (#420). Вопрос был: тянуть Swarm к макету и к системе `dodo/` из forma или нет.

**Что решено.**
- Эталон — текущий интерфейс Swarm Brain. Ребрендинга Swarm под артефакт или под forma не делаем; расхождения доски со старым макетом — не дефект.
- Направление обратное: дизайн-систему forma (`GarroV/forma`, `dodo/`) обновить по канонам Swarm. Работа живёт в репозитории forma.

**Следствия.** #394, #395 и #420 закрыты этим решением. Новые экраны Swarm равняются на существующие экраны Swarm, а не на артефакты и не на forma, пока forma не догонит.
