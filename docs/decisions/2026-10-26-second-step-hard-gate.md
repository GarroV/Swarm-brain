# 26.10.2026 — без Touch ID внутрь не пускаем: ни веб, ни обмен токена, ни ключи из бота

## Повод

26.10 вход по Touch ID стал обязательным ([решение 19.10](2026-10-19-search-and-2fa-deadline.md) §2).
Коллега вошла через Telegram в браузере, где Touch ID не привязан, и увидела пустые экраны в вечной
загрузке («все задачи пропали»). Сервер ей ничего, кроме профиля, не отдал — но веб нарисовал
интерфейс и тихо предложил Touch ID строкой сверху (так было решено 19.10: «без кнопок, не вышло —
одна тихая строка»).

Проверка на живом сервере (26.10): обычная сессия без Touch ID получает отказ на всех разделах, а
веб-сессия, полученная обменом личного токена рекордера или Claude (`meeting-webtoken`), замком не
проверялась и получала доступ ко всему. Ключи Claude и рекордера, кроме того, выдавал Telegram-бот —
без Touch ID.

## Владелец (дословно)

«а почему веб вообще хоть как-то пускает внутрь этого всего ну почему ну нас же по сути должно
развернуть уже на входе сказать нет не проходишь да именно первый пункт действительно сервер связи
пустим обменам токена тоже проверится … по сути пока человек в веби не тыкнул точей ди его не
пускает … ключ мы делаем через личный кабинет в веби, правильно?»

На вопрос «убираем выдачу ключей из Telegram-бота — только личный кабинет в вебе?» — «Да, только веб».

## Что решено

- **Веб разворачивает на входе.** Пока замок включён, а Touch ID в этой сессии не пройден, вместо
  интерфейса — один экран «Подтвердите вход по Touch ID» с кнопкой и «Выйти». Отменяет «тихую строку»
  решения 19.10 для режима, когда шаг обязателен.
- **Обмен токена на веб-сессию тоже под замком.** Сессия из обмена без Touch ID получает только то,
  что нужно окну заметок рекордера во время звонка; остальной веб закрыт.
- **Ключи Claude и рекордера выдаются только в личном кабинете веба**, то есть после Touch ID. Бот на
  просьбу ключа отвечает ссылкой на кабинет. Уже выданные ключи продолжают работать.

## Текст бота и раскатка

Текст ответа бота на просьбу ключа («🔒 Ключи для Claude Desktop и bumblebee теперь выдаются только
в SWARM — после входа с Touch ID. Открой … → Настройки (⚙ внизу слева) → «Claude Desktop» или
«bumblebee». Уже выданные ключи продолжают работать.» + строка по-английски) владелец утвердил: «да».
Раскатка — днём через заморозку, 26.10.2026: «катим сейчас».
