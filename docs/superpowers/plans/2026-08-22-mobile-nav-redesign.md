## Шаги (каждый — свой коммит + живая проверка в браузере)

**Шаг 1. Каркас табов.** `RoyTab` → `task | projects | cal | more`; дом = `task`; `RoyTabBar` — новый набор; «Ещё» из push-роута становится корневым экраном (профиль/выход · База · Команда · Настройки · Админ · Карта · Фидбек); миграция сохранённого `roy_tab` (старые значения `search`/`book` → `task`/`more`, иначе после деплоя у людей с живой сессией пустой экран).
*Проверка:* с каждого таба доступны настройки; рефреш не сбрасывает таб; старое значение в sessionStorage не ломает вход.

**Шаг 2. Единая шапка.** `[аватар → Ещё] Раздел [🔍 → экран ответа]` вместо h1, дублирующего таб. Плейсхолдер поиска — один и тот же во всех точках входа.
*Проверка:* высота хрома до первой строки списка уменьшилась; поиск работает с любого таба.

**Шаг 3. Лаконичные фильтры задач.** Чип-меню «Мои ▾» (линза + «По рынкам» + «Все сотрудники» пунктами), чипы смарт-списков с градиентной маской справа. Тач-цель чекбокса 44×44.
*Проверка:* измерить хром до первой строки (было 199px) и тач-цели (было 19×19).

**Шаг 4. Проекты.** Новый экран: список проектов (имя, прогресс N/M, срочные, подпроекты отступом) → задачи проекта теми же `TaskRow`/`SwipeRow`; «+» создаёт задачу в проекте. Данные — существующие `fetchProjects`/`fetchTasks`.
*Проверка:* тап по проекту открывает его задачи; свайп/тап ведут себя как в списке задач.

**Шаг 5. Встречи.** Очередь вычитки — первая секция внутри экрана (не блок над заголовком) + бейдж на табе; строка встречи получает свайп вместо постоянных карандаша/корзины; единый формат даты. Органы правки названия/тезисов/стран и выбор «Общее/Личное» до согласования — сохранить как есть.
*Проверка:* правка названия и тезисов работает; у несогласованной встречи выбор хранилища на месте, у согласованной — бейдж (решение 21.08 не тронуто).

**Шаг 6. Хвосты.** Один FAB на экране («?» уезжает в «Ещё»); в «Базе» карточка не дублирует content при отсутствии summary; после создания задачи список переключается на тот, где она видна.

**Шаг 7. Смоук-набор.** Скрипты touch-эмуляции (свайп/скролл/тап, обход всех табов) в `miniapp/e2e/`, README с командой запуска. CI заморожен до 01.09 — гоняется локально.

## Границы

- Десктопная вёрстка (≥1024px) не меняется: правки живут в мобильных ветках `RoyApp`/`roy/screens`.
- Бэкенд (`swarm-api`) не трогается: все данные уже отдаются существующими эндпоинтами.
- Выбор хранилища у согласованной встречи не возвращается (решение владельца 2026-08-21).
- Раскатка на команду — только после отдельного «да» владельца.
