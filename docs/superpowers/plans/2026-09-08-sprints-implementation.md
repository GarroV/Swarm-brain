## Этап 3 — экран (следующий, самый дорогой)

### 3.1 Вынести канбан из `SprintBoard.tsx`

Сейчас колонки, DnD и карточка вшиты в компонент доски проектов (687 строк, приколочен к вкладкам).
Нужен общий компонент, который используют и доска, и спринт.

- новый `miniapp/src/components/tasks/TaskKanban.tsx`: колонки по статусам, DnD, карточка;
  принимает список колонок параметром (у доски их 4 с «Бэклогом», у спринта 3 — см. решение владельца);
- `SprintBoard.tsx` переводится на него без изменения поведения.

⚠️ **Единственное место всей фичи, где можно сломать людям работу.** Доска — ежедневный экран.
Проверять до и после: перетаскивание между колонками, создание задачи из колонки, вложенные
подпроекты, приватность проекта (иконка глаза), обе темы.

### 3.2 Экран спринтов

- `miniapp/src/components/tasks/SprintsScreen.tsx` — селектор спринта (активный + архив с фильтром
  по году), шапка с датами и прогрессом, кнопка по состоянию: «Начать спринт» / «Спринт принят» /
  «Открыть отчёт»;
- слева пул **«Задачи»**: задачи воркспейса, не взятые в текущий спринт; поиск, фильтр по проекту
  и исполнителю, добавление по одной и мультивыбором;
- справа канбан из 3.1, карточки сгруппированы заголовками проектов (группировка, не копии);
- вкладка `sprints` в `TasksScreen.tsx` рядом с «Задачи» и «Проекты»;
- методы в `miniapp/src/lib/api.ts` и типы в `types.ts` под роуты `/sprint-cycles*`.

Тексты — сразу двуязычно (EN приоритетный, правило проекта).
