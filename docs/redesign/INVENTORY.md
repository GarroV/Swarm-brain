## Поверхности продукта (не только веб)

| Поверхность | Роль | Затрагивает редизайн |
|---|---|---|
| Веб «Рой» (Next.js → Cloudflare Pages) | доска задач, поиск, вычитка встреч | **да, целиком** |
| Telegram-бот | уведомления (тезисы, комментарии, дайджест, напоминания) | нет (но тексты ссылаются на экраны) |
| Claude Desktop (MCP) | те же данные инструментами | нет |
| bumblebee (macOS) | запись встреч → транскрибация | нет (но статусы видны в вебе) |

## Оси задач (канон `lib/smartLists.ts`) — в макете были упрощены неверно

- **Смарт-список (время):** Сегодня · Ближайшие · Все · Регулярные (скрывается при нуле).
- **Линза (чьи):** мои · команда (общие без исполнителя) · все (мои+командные) ·
  **все сотрудники** (только админ, отдельный тумблер, в переключателе линз его нет).
- **Статус (мультивыбор поверх времени):** открыта · в работе · готова.
- **Тумблер «по рынкам»** — группировка результата, не смена охвата.

## Карта разделов нового интерфейса

| Папка | Раздел | Вкладки / содержимое | Покрывает сейчас |
|---|---|---|---|
| **Работа** | Задачи | Сегодня · Ближайшие · Все · Регулярные · **Архив** (новое) | таб `task`, `taskDetail`, `newTask` |
| | Проекты | Список · Карта (react-flow) · внутри проекта — задачи | `projects`, `project`, `map` |
| | Спринты | Доска · Чек · Аналитика · Журнал | `SprintsScreen`, `sprint-cycles` |
| **Знание** | Встречи | Вычитка · Все встречи · Черновики bumblebee | `cal`, `meetingDetail`, `meetingReview`, `meetAdmin` |
| | База | Записи (transcript · meeting · note · document · summary) · Файлы | `book`/`base`, `record`, `newEntry`, `/entries/upload` |
| **Люди** | Команда | Участники · Воркспейсы | `team`, `/users` |
| **Система** | Настройки | Профиль · Язык · Интеграции (Google, Granola) · MCP-токен · bumblebee · Уведомления | `settings`, `/integrations`, `/mcp/*`, `/recorder/*` |
| | Админ | Пользователи · Воркспейсы · Рассылка · Очередь вычитки · Фидбек | `admin`, `/admin/*`, `/feedback` |

**Глобальный слой (в шапке, на всех экранах):**
поиск по задачам и базе ⌘K → ответ RAG со сносками (заменяет `SearchHero` посреди дашборда —
решение владельца 19.09.2026) · колокольчик уведомлений · личный дайджест · профиль-меню ·
кнопка фидбека.

**Что исчезает:** таб-бар снизу, кнопка «Ещё», дашборд-бенто `RoyDashboard` как отдельный дом.
Его панели не теряются: «Мои задачи»/«Задачи команды» → линзы в Задачах, «Встречи сегодня»/
«На согласовании» → вкладка Вычитка, «Материалы» → База, «Дайджест» → шапка, «Поиск» → шапка.

## Новое, принятое владельцем из первого макета

1. **Архив** задач — вкладка.
2. **Поиск в шапке** вместо поиска посреди главной.
3. **«Взять в работу»** — главное действие в детали задачи.
