# Критический разбор стенда против продукта

Сверено 20.09.2026 с `origin/main` (8540037). Источники правды: `miniapp/src/lib/smartLists.ts`,
`lib/meetingsFilters.ts`, `lib/feedbackCategories.ts`, `components/roy/ui.tsx`,
`components/tasks/*`, `components/AdminScreen.tsx`, `components/SettingsScreen.tsx`.

## Что было не так

1. **Стенд собран тремя слоями обёрток.** Каждое дополнение оборачивало предыдущий экран и
   правило готовую разметку строковыми заменами и регулярками. Работает, но любое следующее
   изменение ломает предыдущее молча. Это главная причина переписать основу, а не дописать
   четвёртый слой.
2. **Словарь статусов не совпадал с продуктом.** В стенде `todo/doing/wait/done`, в продукте —
   `open / in_progress / done` (`STATUS_META`), а «Ждёт» не существует вовсе. Фильтр статусов в
   продукте — мультивыбор ПОВЕРХ оси времени, по умолчанию «открыта + в работе».
3. **Приоритеты выдуманы.** В стенде `P1/P2`, в продукте — `high / med / low` (`PRI_COLOR`).
4. **Данных было девять задач и шесть встреч.** На такой выборке не видно ни линз, ни
   группировки по рынкам, ни фильтров: любой срез выглядит одинаково.
5. **Действия были декоративными.** Кнопки открывали модалку, но ничего не меняли: задача не
   создавалась, фильтры-чипы не фильтровали, комментарий не добавлялся, статус не менялся.
6. **Фильтры встреч были тремя заглушками.** В продукте это шесть осей: строка поиска, период
   (всё / неделя / месяц / квартал / произвольный), страны, источники, люди, хранилище
   (общее / личное), статус (подтверждена / ожидает).
7. **Категории фидбека были выдуманы.** В продукте их одиннадцать и они зафиксированы кодами:
   bumblebee, встречи, поиск, задачи, база знаний, дайджест, вход, интеграции, Claude/MCP,
   интерфейс, другое.
8. **Целых поверхностей не было.** Очередь вычитки агентских встреч (`MeetAdminScreen` — 1752
   строки, самый большой экран продукта), сбор задач из встречи, таймлайн, пул инициатив
   спринта с диалогом приёмки, редактор меток, выбор страны, профиль пользователя в админке с
   привязкой email, рассылка, команды установки рекордера, генерация дайджеста, подключение
   Google и Granola, выход из аккаунта.

## Что сделано вместо этого

Стенд переписан на явную основу: данные → хранилище состояния → экраны. Ни одной строковой
правки чужой разметки. Действия меняют состояние и перерисовывают экран, фильтры считают по
данным, а не по подписям. Данных заведено столько, чтобы срезы отличались друг от друга.

Файлы: `stand/js/data.js` (тестовые данные), `store.js` (состояние и действия),
`ui.js` (атомы), `screens-*.js` (экраны), `detail.js` (правая панель), `app.js` (каркас).
Проверка — `node docs/redesign/stand/check.js`, негативный прогон — `check.js break`.

# Сверка 21.09.2026: что выдумано, что потеряно

Повод — владелец: «перепроверь функционал. нам его надо просто перенести, а не выдумывать
новый. сейчас много что нового напридумывал, и убрал старое». Сверено с `origin/main`
(`miniapp/src/components/**`, `lib/initiatives.ts`, `lib/smartLists.ts`) и со схемой прод-базы
(`sprints`, `sprint_cycles`, `sprint_items`, `projects`, `task_labels`) — не по памяти.

## A. Выдумано в стенде (в продукте этого нет)

| Выдумка | Как в продукте |
|---|---|
| «Инициативы» — очередь предложений с «Принять в цикл» / «Снять» | Инициатива — это **подпроект**, а направление — проект верхнего уровня (`lib/initiatives.ts`). Никакой очереди предложений нет; принимают **спринт**, а не инициативу |
| «Цикл», «Закрыть цикл» | Спринт: «Начать спринт» → сверка → «Принять спринт» (диалог приёмки, перенос незакрытых с причиной, следующий создаётся встык) |
| Массовое выделение задач и групповые действия | В продукте выделения нет вовсе |
| Настройка колонок доски (вкладка «Колонки доски») | Колонки фиксированы: Бэклог · Открыто · В работе · Готово |
| Вкладка «Карта проектов» | Дерево react-flow **отключено владельцем 06.08.2026**; работа по проектам ведётся на доске |
| Статус задачи «бэклог» отсутствовал | В проде это живой статус: 13 задач на 21.09.2026 |

## B. Потеряно при переносе (в продукте есть, в стенде не было)

**Проекты.** Продовый экран «Проекты» — это доска: вкладки досок сверху (создать,
переименовать, удалить), проекты секциями, внутри колонки Бэклог/Открыто/В работе/Готово,
подпроекты со своими колонками, перетаскивание задач между колонками и секциями, быстрое
добавление задачи прямо в колонку, приватность проекта (только я / вся команда), сворачивание.
В стенде была сетка карточек — это мобильный экран, а не рабочий.

**Спринты.** Пространства (`sprint_cycles.tab_id`), выбор спринта сверху, «Новый спринт»,
переименовать, удалить, «Начать спринт», «Принять спринт» с диалогом приёмки, отчёт («Итоги
спринта», кто сколько закрыл, по проектам, закрытия по дням, сверх плана, перенесено, итог
словами), пул свободных задач слева с фильтрами, группировка «по инициативам / по людям»,
сверка (по плану / риск / проблема / не отмечено), пометка «к переносу» с причиной и счётчиком
переносов, «сверх плана» (`in_plan=false`), архив спринтов, причины переносов в аналитике,
журнал за День/Неделю/Всё.

**Задачи.** Пинг-напоминание («Напомним в этот день», «Убрать пинг», «Уже напомнили»),
пользовательские списки задач (в продукте метки называются **«Списки»**, в рельсе — «Мои
списки»), фильтр по периоду, несколько исполнителей у задачи.

**Встречи.** Переобработка тезисов с вариантами (короче / подробнее / акцент на решениях /
своё пожелание / просто пересобрать), «Пометки на полях» из рекордера с автором, транскрипт
репликами «спикер: текст» с таймкодами, копирование тезисов, переименование встречи.

**База.** «В задачу» из записи, «Кратко от ИИ», скачивание файла.

**Главная.** Панель «Задачи команды», состояния календаря (не подключён / доступ истёк / идёт
сейчас), кнопка «Карта проекта».

**Шапка.** Полоса «Идёт обновление — страница перезагрузится сама».

## C. Осознанные отличия (не возвращать без слова владельца)

- Смарт-списки Сегодня/Ближайшие/Все сняты с вкладок: срок виден группами в самом списке,
  «регулярные» и «архив» — тумблеры. Решение принято при переделке шапки фильтров 21.09.
- Поиск переехал в шапку (канон 19.09), дайджест — тоже.
- Вид «Инициативы» в спринтах снят владельцем 19.09 — в стенд не возвращается.
