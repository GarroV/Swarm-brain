# Критический проход по стенду — журнал

Задача владельца: «сделай очень критический проход по тому что сейчас, перенеси весь
функционал в прототип. чтобы все щелкалось и двигалось. залей тестовые данные».

**Метод (повторять для каждого экрана):** снимок глазами → починить конкретный случай →
добавить в `check.js` правило на КЛАСС дефекта → доказать, что правило падает на
намеренно сломанной копии → прогнать `node docs/redesign/stand/check.js` до зелёного →
коммит и пуш в `feat/redesign-ui`.

Негативный прогон обязан сперва убедиться, что поломка применилась (строка найдена):
молча не применённая поломка даёт ложно-зелёный «негативный прогон».

## Закрытые классы дефектов

- разрушительное действие без подтверждения (удаление записи, метки, инициативы, слияние
  дублей, сброс колонок, закрытие цикла);
- ячейка, обрезанная CSS, без доступа к полному тексту (`titleClipped`);
- счётчик, считающий не тот список: обрезанный поиском, не реагирующий на фильтры
  (встречи), называющий соседние вкладки;
- расхождение чисел между видами одной сущности: проект (список/карта/панель), цикл
  (доска/чек/аналитика/**таймлайн**);
- контрол, который молча ничего не делает: фильтры на вкладке «Файлы», «Закрыть цикл»,
  мёртвый `accept-init`, «В архив» над уже архивным;
- две подписи у одного действия («Задачи из встречи» / «Собрать из тезисов»);
- подпись, обещающая не то («Привязать почту», «Переключить» без имени цели);
- созданное не видно в списке, который его не показывает (`revealTask`);
- машинный формат даты в интерфейсе; состояние голым текстом вместо плашки;
- данные, теряемые при смене воркспейса.

## Известные шероховатости самого прогона

- ~~**Прогон изредка врёт** (примерно 1 раз на 8–10)~~ — починено 20.09.2026 (#422):
  стенд тянет шрифты с fonts.googleapis.com с `display=swap`, и первый замер успевал
  уйти по запасному шрифту — он шире, отчего «заголовок колонки обрезан». Перед первым
  снимком ждём `window.__renders`, каркас и `document.fonts.ready`. Шесть прогонов
  подряд зелёные. Прежний симптом (историческая справка, 1 раз на 8–10): то «НЕТ ЭЛЕМЕНТА
  `[data-act="sec"][data-id="map"]`», то обрыв на первом экране с «заголовок колонки
  обрезан: Срок» и отсутствующим `.bar .drop .btn`. Похоже на незавершённую первую
  отрисовку: перед первым замером нет ожидания готовности страницы. Чинится ожиданием
  `window.__renders`/готовности каркаса сразу после `goto`, как уже сделано в `click()`.
  До починки: повторить прогон, зелёный после красного без правок = флак.
- Тёмная тема в стенде выведена руками; при переносе в реальный код брать ядро из
  `dodo-ds.css`.
