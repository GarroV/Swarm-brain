# Подключение Claude Desktop к Swarm Brain (macOS)

## Самый простой способ — `/setup` (рекомендуется)

1. В боте напиши **`/setup`**.
2. Бот пришлёт **одну команду** с уже вшитым твоим токеном.
3. Открой приложение **Терминал** (⌘+Пробел → набери «Терминал» → Enter), вставь команду (⌘+V), нажми Enter.
4. Скрипт сам всё поставит (включая Node, если его нет — без пароля, в твою домашнюю папку), пропишет коннектор и перезапустит Claude Desktop.

Готово — в Claude появится сервер **swarm-brain** с инструментами. Дальше создай проект и вставь в **Instructions** текст из команды `/claude`.

> Что делает команда: качает скрипт с `…/functions/v1/swarm-setup` и запускает его с твоим токеном (`SWARM_TOKEN=…`). Скрипт безопасно **дописывает** блок `swarm-brain` в `~/Library/Application Support/Claude/claude_desktop_config.json`, не трогая другие серверы (и делает бэкап). Токен в команде — личный, действует 90 дней, отозвать: `/revoketoken`.

### Если что-то пошло не так
- **«command not found» / нет интернета / прокси режет** — скрипт напишет понятную ошибку. Чаще всего достаточно проверить интернет и запустить команду из `/setup` ещё раз.
- **Claude Desktop не установлен** — поставь его, открой один раз, потом запусти команду из `/setup`.
- Команду можно запускать сколько угодно раз — она просто обновит настройку (старый токен при этом перевыпускается).

## Ручная настройка (для технических, опционально)

Если не хочешь автоскрипт — можно прописать конфиг руками.

1. В боте: **`/mytoken`** — получишь токен `smcp_…`.
2. Создай/открой `~/Library/Application Support/Claude/claude_desktop_config.json` и добавь блок (не затирая существующие серверы):

```json
{
  "mcpServers": {
    "swarm-brain": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://vbqglndbxkpmreccpqmr.supabase.co/functions/v1/swarm-mcp",
        "--transport", "http-only",
        "--header", "Authorization:${AUTH_HEADER}"
      ],
      "env": { "AUTH_HEADER": "Bearer smcp_ТВОЙ_ТОКЕН" }
    }
  }
}
```

3. Нужен Node (`mcp-remote` гоняется через `npx`). Если Claude Desktop пишет «npx not found» — укажи в `command` **абсолютный путь** к `node`, а первым элементом `args` — абсолютный путь к `npx` (GUI-приложение не наследует PATH шелла). Это именно то, что автоскрипт делает за тебя.
4. Полностью выйди из Claude Desktop (**Cmd+Q**) и открой заново.

> ⚠️ Никогда не используй поле `"url"` / `"type":"http"` в `claude_desktop_config.json` — Claude Desktop его не понимает и **молча стирает весь блок `mcpServers`** (баг anthropics/claude-code#37286). Только форма с `command` + `mcp-remote`.

## Доступные инструменты

| Инструмент | Что делает |
|---|---|
| `add_knowledge` | Добавить текст в базу (или личное хранилище) |
| `upload_file` | Загрузить файл в Storage + создать запись |
| `search_knowledge` | Найти информацию (включая личные записи) |
| `get_entry` | Полный текст записи по ID |
| `get_tasks` | Задачи команды с фильтрами |
| `get_meetings` | Последние встречи |
| `get_users` | Список команды с профилями |
| `get_storage_stats` | Статистика базы |
| `list_entries` | Список записей для ревизии |
| `delete_entry` | Удалить запись |
| `update_entry` | Обновить запись или заменить файл |
