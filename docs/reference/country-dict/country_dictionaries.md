# Словари по странам — облака тегов для ревью (v2)

> Консолидировано из `keys_all.yaml` (источник истины по людям/вендорам) + расширенное гео.
> **Правило v2:** «пиццерии» схлопнуты в «города» — нужен ТЕГ, а не инвентарь точек.
> Голый город ловит «Город-1/2/10». Номера выкинуты. Склонения добирает стеммер.
> Гео + города = вес 2. Голые ISO-коды не здесь (ловятся в заголовке).
> **Имена сверь по своему `keys_all` — при переносе мог ошибиться в написании.**
> «⚠️ тонко» = категория почти пустая, кандидат на харвест (Gmail/прод-корпус).
