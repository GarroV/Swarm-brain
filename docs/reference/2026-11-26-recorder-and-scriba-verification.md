# Проверка оставшихся исправлений рекордера и scriba

Дата: 26.11.2026. Совмещено с production-ревизией новой главной `5d991735`.

## Рекордер

`meeting-status` явно возвращает недоступные ID без раскрытия чужих встреч.
Рекордер прекращает их опрос с сохранением флага после перезапуска; резерв
аудио остаётся до прежнего трёхсуточного срока. Старый сервер и временный
HTTP 503 не прекращают повторные попытки.

Изолированный прогон настоящих `SwarmClient` и `UploadQueue` на отдельных
файлах и подставных HTTP-ответах: `--selftest-status-poll` PASS. Проверены 503,
старый ответ, недоступная встреча, перезапуск, сохранность аудио и истечение
TTL. Swift build PASS; два серверных теста, Deno check и lint PASS.

## scriba

Подготовленный PR #1312 совмещён с текущим кодом. Пропуск встречи получен
от двойника сервера; неизвестный пропуск отклоняется с 401. Целевой тест
этого контракта, TypeScript, ESLint и Prettier PASS.

На MUSPELHEIM собран отдельный образ и выполнены настоящие контейнерные
прогоны Chromium и ffmpeg с изолированным серверным транспортом:

- Оркестратор: запись и отправка (`full`), смерть контейнера (`death`) — PASS.
- Пульс: штатный конец без ложного алерта (`end`) — PASS.
- Пульс: смерть контейнера и оповещение владельцу (`death`) — PASS.
- Пульс: претендент не забирает право одним claim; измеренная выгрузка
  передаёт право, бот выходит `superseded`, ложного алерта нет (`takeover`) — PASS.

Первый `end` выявил отставшую схему стенда. Штатный `stand_guard` применил
миграцию `20261123170000`, после чего подтвердил 182 миграции `main`.
Повторён только не прошедший `end`; прошедшие `death` и `takeover` не повторялись.
Telegram и OpenAI заменены двойниками. Прогон не отправлял людям сообщения
и не вызывал модели. Тестовые контейнеры удалены сценарием.

Это не проверка живого звонка с владельцем и не выпуск новой сборки рекордера.
Живой сценарий подстраховки остаётся в отдельной задаче.
