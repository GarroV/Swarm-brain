# Карта рынков (market roster) — справочник страновой атрибуции

> **Назначение:** признаки, по которым встреча однозначно причисляется к рынку. Используется классификатором (слой B спеки `2026-07-30-country-attribution-design.md`): подсказка в промпт + детерминированный арбитр. Источник правды для `_shared/market-roster.ts` (код миррорит этот файл).
>
> **Признаки — только ДВА измерения (решение владельца):** **города** + **свои люди**. Измерение «термины/темы» убрано целиком как шумное. Люди пересекаются между рынками (напр. **Антон** есть и в SI, и в RS) → один признак не решает; рынок берёт тег, когда его комбинация {города ∪ свои люди} явно доминирует и он единственный лидер, иначе → General.
>
> **Источники:** 🔬 из наших встреч · 🗣 со слов владельца · 🔎 ресёрч · ⬜ ждём владельца · ❓ подтвердить.
>
> **Статус:** 🟡 наполняется. Готовы: RS. Остальные — черновик из базы, ждут правки владельца.

## Правила использования (арбитр)
1. Заголовок-паттерн 1:1 / weekly / sync ИЛИ ≤2 участника → **General** (ростер не смотрим).
2. Иначе: скорим рынки по совпадениям **{города ∪ свои люди}** в заголовке + тезисах.
3. Один явный лидер → его тег. Ничья / ≥2 сильных / никого → **General**.
4. «Общие» люди (Александра, Саша, Кирилл, Vasiliy — фигурируют везде) в скоринг НЕ идут.
5. Пустой ростер по стране = fallback на LLM+сентинел.
