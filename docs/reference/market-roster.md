# Карта рынков (market roster) — справочник страновой атрибуции

> **Назначение:** признаки, по которым встреча однозначно причисляется к рынку. Используется классификатором (слой B спеки `2026-07-30-country-attribution-design.md`): подсказка в промпт + детерминированный арбитр. Источник правды для `_shared/market-roster.ts` (код миррорит этот файл).
>
> **Как работает атрибуция:** люди пересекаются между рынками (напр. **Антон** есть и в SI, и в RS) → один признак НЕ решает. Рынок получает тег, только когда его **комбинация** признаков (город + свои люди + термины) явно доминирует и он единственный лидер; иначе → General.
>
> **Источники признаков:** 🔬 из наших встреч (база прода) · 🔎 из открытого ресёрча присутствия Dodo · ⬜ ждём владельца · ❓ спорно, подтвердить.
>
> **Статус:** 🟡 черновик на правку с владельцем.

## Правила использования (арбитр)
1. Заголовок-паттерн 1:1 / weekly / sync ИЛИ ≤2 участника → **General** (ростер не смотрим).
2. Иначе: скорим рынки по совпадениям {города ∪ свои люди ∪ термины} в заголовке+тезисах.
3. Один явный лидер → его тег. Ничья / ≥2 сильных / никого → **General**.
4. «Общие» люди (Александра, Саша, Кирилл, Vasiliy — фигурируют везде) в скоринг НЕ идут или с малым весом.
5. Пустой ростер по стране = fallback на LLM+сентинел.
