# Проверка локальных шрифтов

Основа: main `b79c1d1a`, Next 16.4.6. Исправление #1620 касается автономности
шрифтов приложения; прежнее исправление URL-парсинга Next не менялось.

## Состав

13 семейств, 77 неизменённых WOFF2 (1 432 960 байт), 89 исходных Unicode faces.
Файлы совпадают с main-derived build побайтно. В каждом каталоге — OFL;
`miniapp/src/fonts/manifest.json` содержит SHA-256, версии и официальные источники.
Сохранены все веса, диапазоны символов и метрики 13 резервных шрифтов.
8 preload-файлов совпадают с прежними выбранными сабсетами побайтно.

## Фактические проверки

- Production build PASS с блокировкой `fonts.googleapis.com` и
  `fonts.gstatic.com` в Node; Google CSS test hook Next получил пустую карту,
  поэтому оставшийся Google loader не смог бы собрать приложение.
  Остальная сеть и установка npm-зависимостей не блокировались.
- Линт: 651 файл, 215 прежних диагностик, 0 регрессий.
- `schemes.test.ts`: 24 PASS. Контракт проверяет подключение локальных font chains
  из корневого layout, публичные CSS aliases и их ссылки на localFont-переменные.
- Сгенерированный CSS: 89 faces имеют исходные SHA-256, веса и Unicode ranges;
  13 fallback-метрик и 8 preload-файлов соответствуют baseline.
- Chrome for Testing 158: ширины EN/RU текста для 13 семейств при весах 400/600
  совпали с baseline. Промежуточного Arial fallback между сабсетами нет.
- Снимки Projects 1440×1000 после загрузки шрифтов и отключения анимаций:
  0 отличающихся пикселей. Запросов к Google font hosts — 0.
- Реальный Download HTML в Market analysis: скачанный HTML открыт отдельно
  с заблокированной внешней сетью. Вычисленные переменные — `"Inter"` и
  `"JetBrains Mono"`, основной font-family начинается с Inter; ссылок на
  приватные localFont-переменные в этих значениях нет. Экспорт использует
  общую snapshot-функцию для HTML и PDF.

Экспорт рынка в отдельный HTML/PDF сохраняет прежнюю ссылку на Google Fonts
и системный fallback; автономность приложения не означает автономность этих
файлов. Экспортные Inter/JetBrains-переменные имеют приоритет над CSS приложения.

`miniapp/out` через browser route fulfillment, с теми же реальными публичными
GET API и авторизацией demo. Подменялась только статика, DOM и данные не имитировались.
