# Марка bumblebee

`BeeMark.png` — рисунок шмеля, из которого делается **всё**: иконка приложения (`AppIcon.icns`),
значок в меню-баре (template — macOS красит его под тему сама) и марка в плавающем виджете.
Источник один намеренно: раньше фигура рисовалась кодом, и любая правка требовала синхронизации
трёх мест.

| Файл | Что это |
|---|---|
| `BeeMark.png` | рабочая марка: 1024×1024, белый рисунок на прозрачном фоне, поля 6% |
| `BeeMark-source.jpeg` | исходник от владельца (белое на чёрном, 2048×2048) — на случай пересборки |
| `extract-mark.swift` | чем `BeeMark.png` получен из исходника |

## Как пересобрать марку из нового исходника

```sh
swiftc -O -o /tmp/extract Resources/extract-mark.swift
/tmp/extract Resources/BeeMark-source.jpeg Resources/BeeMark.png 1024 0.06
./gen-icon.sh          # пересобрать AppIcon.icns
```

Скрипт делает прозрачность из яркости (белое → непрозрачное), обрезает по содержимому и вписывает
в квадрат с полями. Две ловушки, на которые он уже наступил и которые обходит:

- **пиксели, а не точки.** `NSImage.size` отдаёт размер с поправкой на DPI — у этого JPEG выходило
  491 вместо 2048, то есть вчетверо меньше деталей. Размер берётся у representation.
- **альфа умножается на цвет.** `NSBitmapImageRep` хранит premultiplied-пиксели: записать белый
  как 255 при полупрозрачной альфе — значит получить сплошной белый квадрат вместо рисунка.

## Требования к новому исходнику

Белый рисунок на чёрном (или сразу PNG с альфой), 1024×1024 и больше, одноцветный, без градиентов,
теней и текстур. Линии не тоньше ~3.5% от полотна и не ближе ~4% друг к другу — иначе в меню-баре
(18 pt) они сливаются в пятно.
