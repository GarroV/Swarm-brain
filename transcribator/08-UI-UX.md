# 08 — UI/UX: дизайн-система Swarm (веб + Mini App + macOS-агент)

Единая дизайн-концепция трёх поверхностей: десктоп-веб (полноценный рабочий инструмент), Telegram Mini App (мобильная перестройка), macOS-агент записи встреч (меню-бар, Tauri). Направление выбрано из трёх независимых концепций (редакционная, рабочий инструмент, Telegram-native) панельным сравнением.

## Направление и принципы

**«Плотный рабочий инструмент»** — эстетика Linear/Notion/Height: высокая информационная плотность, сайдбар вместо телефонного таб-бара на десктопе, split view «список + деталь», командная палитра ⌘K, моноширинные акценты для метаданных. Цвет — только там, где несёт смысл (статусы).

Айдентика: **Рой = пчёлы = мёд.** Фирменный акцент — янтарно-медовый, основа — тёплый графит/бумага вместо чисто-серого. Глиф — шестиугольная сота (логотип, иконка меню-бара агента).

Принципы:
1. Один набор токенов на три поверхности. Агент потребляет их через `design-tokens.json`, генерируемый из `globals.css`.
2. Одна встреча проживает путь «янтарный (запись/обработка) → зелёный (готово/подтверждено)» одинаково в меню-баре, уведомлении и вебе.
3. Глубина — borders-first: hairline-линии и ступени поверхностей, тени только у поповеров/шитов.
4. Русский язык всюду. Единый словарь UI-строк, никакой смеси «In Progress» / «Доска».
5. Никаких эмодзи-иконок и сырых telegram ID. Иконки — lucide, имена — резолв через `/users`.

## Дизайн-токены

### Палитра (oklch)

Ахроматика с тёплым подтоном (hue ~90), медовый акцент, четыре семантических статуса.

```css
:root {
  /* Основа — тёплая бумага, не чистый белый */
  --background:        oklch(0.978 0.003 90);
  --foreground:        oklch(0.215 0.01 90);
  --surface:           oklch(1 0 0);            /* карточки, панели */
  --surface-sunken:    oklch(0.962 0.004 90);   /* колонки канбана, фильтры, спойлеры */
  --surface-raised:    oklch(1 0 0);            /* поповеры, палитра ⌘K */
  --border:            oklch(0.90 0.005 90);
  --border-strong:     oklch(0.82 0.006 90);
  --muted-foreground:  oklch(0.50 0.012 90);

  /* Бренд: мёд */
  --accent:            oklch(0.72 0.135 78);    /* primary-кнопки, активная навигация */
  --accent-foreground: oklch(0.22 0.04 78);
  --accent-soft:       oklch(0.95 0.035 85);    /* подложка активных состояний */

  /* Семантика статусов (общая для веба, Mini App и агента) */
  --status-done:       oklch(0.62 0.14 150);    /* подтверждено / отправлено / done */
  --status-progress:   oklch(0.58 0.12 250);    /* in progress / транскрибация */
  --status-pending:    oklch(0.72 0.14 70);     /* ожидает / processing / запись */
  --status-danger:     oklch(0.56 0.20 27);     /* ошибка / удаление / REC */
  /* у каждого статуса пара *-soft для подложек бейджей: L≈0.94, C≈0.04 */
}

.dark { /* тёплый графит, не #000 */
  --background:        oklch(0.185 0.006 90);
  --foreground:        oklch(0.94 0.005 90);
  --surface:           oklch(0.225 0.007 90);
  --surface-sunken:    oklch(0.165 0.006 90);
  --surface-raised:    oklch(0.265 0.008 90);
  --border:            oklch(1 0 0 / 9%);
  --border-strong:     oklch(1 0 0 / 16%);
  --muted-foreground:  oklch(0.66 0.01 90);
  --accent:            oklch(0.80 0.125 83);
  --accent-foreground: oklch(0.24 0.05 80);
  --accent-soft:       oklch(0.30 0.045 80);
  /* статусы: L +0.08, C −0.02 от light-значений */
}
```

**Цвет рынков (HU, RS, ME — ~25 стран):** детерминированный, без ручной раскраски: `hue = hash(code) % 360`, light: `L 0.75 / C 0.06`, dark: `L 0.40 / C 0.05`. Вместо нынешних одинаковых серых пилюль.

### Типографика

Две семьи, обе variable, обе с полной кириллицей (Google Fonts, подключать через `next/font/google` с `subsets: ["cyrillic","latin"]`):

- **Golos Text** (400–900) — весь UI и заголовки. Рисован под русский язык, плотный. Иерархия — весом (500/600/750), не сменой гарнитуры.
- **JetBrains Mono** (variable) — метаданные: даты, таймстампы транскрипта `[12:34]`, коды рынков, длительность, счётчики, хоткеи.

Шкала (десктоп — плотный 13px-базис; мобила 15px; редактор тезисов 16px — iOS не зумит):

| Токен | Размер/интерлиньяж | Применение |
|---|---|---|
| `--text-xs` | 11/16 mono | таймстампы, хоткеи, коды рынков |
| `--text-sm` | 12/16 | вторичные подписи, бейджи |
| `--text-base` | 13/20 | строки списков, тело UI (desktop) |
| `--text-md` | 15/22 | тело UI mobile; 16 — редактор тезисов |
| `--text-lg` | 18/24 · 600 | заголовки панелей, название встречи в детали |
| `--text-xl` | 24/30 · 700 | заголовок страницы-редактора |
| `--text-2xl` | 32/38 · 750 | h1 экранов |

### Spacing, radius, поверхности, состояния

- **Сетка 4px, ритм неравномерный:** внутри строки 4/8, между связанными блоками 12, между секциями 24, между зонами экрана 32/48. Высота строки списка: 36px desktop / 48px mobile (touch target ≥44px).
- **Radius:** `--radius: 6px` (сейчас 10 — слишком «надувной»). Контролы 6, карточки 8, поповеры/шиты 10, пилюли — full.
- **Тени — borders-first.** Ур.0 — только `--border`; ур.1 (hover карточки, поповер) — `0 1px 2px oklch(0 0 0/6%), 0 4px 12px oklch(0 0 0/7%)`; ур.2 (палитра, модалки, шиты) — `0 8px 32px oklch(0 0 0/14%)`. В dark глубина — ступенями `--surface-*`.
- **Состояния:** hover — `--surface-sunken`; focus-visible — кольцо 2px `--accent` со смещением; active — лёгкое затемнение, без scale-подпрыгиваний. Переходы 120–150ms, только compositor-friendly свойства.

## Десктоп-веб (≥1024px)

### Каркас: сайдбар вместо таб-бара

```
┌────────────┬──────────────────────────────────────────────┐
│ ⬡ Рой      │ Хедер экрана 48px: заголовок · фильтры ·     │
│ [Найти ⌘K] │ переключатель видов · primary-действие       │
│            ├──────────────────────────────────────────────┤
│ Встречи (3)│                                              │
│ Задачи     │           контент, max-w 1680px              │
│ База       │   (канбан/таймлайн/граф/split — вся ширина)  │
│ Команда    │                                              │
│ ─────────  │                                              │
│ Админ      │                                              │
│ Настройки  │                                              │
│ ─────────  │                                              │
│ ◉ Василий  │                                              │
└────────────┴──────────────────────────────────────────────┘
```

- Сайдбар 240px, сворачивается в рельсу 56px (состояние в localStorage). Активный пункт: подложка `--accent-soft` + вес 600 + медовая полоса 2px слева. Счётчик «не просмотрено» у Встреч.
- Низ сайдбара: аватар + живое имя из `/me`, переключатель темы.
- Никаких fixed-кнопок во всю ширину: действия в хедере и в строках.
- **⌘K — командная палитра** (`cmdk`): семантический поиск (существующий endpoint), переходы, действия («Новая задача», «Подтвердить встречу»). Главный жест скорости.

### Встречи: split view

- **Левая панель 380px** (resize): строки-встречи, сгруппированные по датам («12 июня, среда»). Строка: статус-точка (янтарная — не подтверждена, зелёная — подтверждена, синяя пульсирующая — «готовим тезисы») + название 13/600 + mono-строка `14:00 · 47 мин · desktop-agent · HU RS`. Непросмотренные — вес 600 + точка-маркер. Сверху: поиск + фильтры (источник/рынок/статус). Навигация ↑↓, Enter, `e`.
- **Правая панель** — деталь, URL синхронизирован: `/meetings/[uid]` — тот же адрес, что deep link из уведомления агента.

### Страница встречи-редактора `/meetings/[uid]`

Раскладка «документ + рельса»:

- **Центральная колонка ≤760px (текст ~70ch):** тезисы, markdown-редактор «Правка/Просмотр» (segmented control). Текст 15/24. Sticky-бар «Сохранить ⌘S · Отменить» появляется только при изменениях. Конфликт `notes_edited_at` — янтарная плашка над редактором, не модалка.
- **Правая рельса 280px:** mono-метаданные (дата, длительность, источник, владелец), участники (аватары+имена); **задачи встречи** строками со статус-точками + «Обновить задачи из тезисов»; внизу опасная зона: «Перегенерировать тезисы» (confirm-поповер «Затрёт текущий текст»), «Удалить».
- **Под колонкой два аккордеона** (свёрнуты): «Транскрипт» — сегменты: mono-таймстамп `[12:34]` в колонке 64px слева, текст справа; «Мои пометки во время встречи» — user_notes в том же паттерне. Это визуальный мостик к окну пометок агента.
- `summary_status: processing` — скелетон + «Готовим тезисы…» с пульс-точкой и авто-поллингом.

### База знаний

Три зоны: **рельса фильтров 200px** (тип, рынки с цветными точками, «только мои», приватные) → **список-таблица** (строки 36px: lucide-иконка типа, заголовок + первая строка, мини-пилюли рынков, mono-дата, замок приватности) → **панель предпросмотра 420px** по клику (Редактировать/Удалить — для владельца). **Поиск — главный объект экрана:** крупное поле над списком с подсказкой («поиск понимает смысл, не только слова»), дублируется в ⌘K.

### Задачи

Хедер: segmented control «Доска · Таймлайн · Спринт · Граф» (hotkeys 1–4), фильтры-пилюли «Открытые · В работе · Готово» (по-русски!), фильтр по исполнителю (аватары), «+ Задача» (`c`).

- **Доска** — вся ширина: колонки 320px на `--surface-sunken`. Карточка: название 13/500, низ — аватар исполнителя (имя по hover), mono-дедлайн (красный при просрочке), точки рынков. Только lucide.
- Деталь задачи — правый **drawer 480px** (не модалка): правка на месте, связь со встречей-источником.

## Мобила (Telegram Mini App, <1024px)

Тот же код и токены, перестраивается каркас:

- **Нижний таб-бар остаётся** (правильный мобильный паттерн): 5 пунктов — Задачи, Встречи, База, Команда, Ещё (Настройки+Админ внутри). Высота 56px + `safe-area-inset-bottom`. Активный таб — медовая иконка + подпись 600.
- **Split view схлопывается в стек:** список → тап → страница `/meetings/[uid]` целиком. Назад — **Telegram BackButton** (SDK).
- **Главное действие — Telegram MainButton** («Сохранить тезисы», в цветах темы клиента); в браузерной мобиле — sticky-кнопка. Текущие чёрные полосы во всю ширину удаляются.
- **Диалоги → bottom sheets:** деталь записи/задачи, фильтры — шит с грипом, 85vh, свайп вниз. Один компонент `DetailSurface`: desktop → правая панель/drawer, mobile → шит. Confirm — нативный `showConfirm` из SDK.
- **FAB** 56px (медовый) справа внизу над таб-баром, контекстный («+ задача» / «+ запись»).
- **Мост темы Telegram:** из SDK берём только `colorScheme` (→ класс `.dark`) и `setHeaderColor`/`setBackgroundColor` под `--background`; палитру themeParams внутрь НЕ пускаем — айдентика своя. Хаптика на смену статуса/сохранение.
- Редактор тезисов: 16px, «крупный шрифт + сохранение снизу» — требование 05 закрыто MainButton.
- Канбан — горизонтальный свайп колонок со snap; Граф — read-only с pinch-zoom.

## macOS-агент (Tauri, меню-бар)

Снаружи — нативный macOS (template-иконки, vibrancy), внутри панелей — токены Swarm (Golos, мёд, статусные цвета). Узнавание через форму (сота) и статусную семантику, не через перетаскивание веб-UI.

### Иконка меню-бара (template image, монохром по HIG)

| Состояние | Иконка | Дополнительно |
|---|---|---|
| Ожидание | контурная сота | — |
| Запись | залитая сота + красная точка | tooltip «Идёт запись · 23:41» |
| Транскрибация | сота с вращающимся сегментом по контуру | прогресс в дропдауне |
| Отправлено | сота + галка (3 сек → контур) | нотификация с deep link |
| Ошибка/очередь | сота + «!»-бейдж | в дропдауне «Переотправить» |

**Дропдаун-панель** 320px (NSVisualEffectView): статус с цветной точкой (те же `--status-*`), последняя встреча (название · mono-длительность · статус доставки), очередь неотправленных, кнопки «Переотправить последнюю», «Открыть Рой». Golos 600 13px / JetBrains Mono 11px.

### Окно пометок (появляется с детектом встречи)

Floating-панель **320×400** поверх окон:
- Шапка-грип 32px: красная пульс-точка + mono-таймер `00:23:41` + «свернуть в меню-бар» + pin. Свёрнутый вид — пилюля 120×36 (REC + таймер), перетаскиваемая.
- Тело: plain-text; каждая строка при начале ввода получает слева mono-таймстамп `[23:41]` цветом `--muted-foreground` — **ровно тот же паттерн, что транскрипт и пометки в веб-редакторе**. Человек видит свои пометки в вебе в той же форме.
- Фон: тёмный графит `oklch(0.185 0.006 90 / 92%)` + blur — узнаваем на любом фоне.

### Онбординг (окно 560×440, прогресс-точки мёдом)

1. **Разрешения macOS** (микрофон, screen & system audio, календарь) — строки с зелёными галками по мере выдачи, кнопки открывают нужную панель System Settings.
2. **Модель STT** — медовый прогресс-бар, mono-подпись `412 / 604 МБ`.
3. **Кто вы** — список команды с сервера (аватары + имена, тот же атом-строка, что в вебе).

Финал: «Готово. Агент живёт в меню-баре» со стрелкой к соте. Шрифты Golos/JetBrains Mono вшиты в бандл.

### Стыковка

Токены — в `design-tokens.json` (генерируется из `globals.css`), форк anarlog (`plugins/swarm/`) читает его для поповера, окна пометок и онбординга. Правка палитры доезжает до агента пересборкой.

## План миграции с текущего кода

Текущая база: Tailwind 4 `@theme inline`, shadcn-примитивы в `miniapp/src/components/ui/`, Base UI, lucide. Эволюция, не переписывание.

1. **Шрифты (полчаса, чинит «Times»).** `layout.tsx`: `next/font/google` → `Golos_Text({subsets:["cyrillic","latin"], variable:"--font-sans"})` + `JetBrains_Mono(... variable:"--font-geist-mono")`, классы на `<html>`. Сейчас `globals.css:10` (`--font-sans: var(--font-sans)`) — циклическая самоссылка → invalid → браузерный serif. После подключения каскад заработает без правок CSS.
2. **Токены (один файл).** Переписать `:root`/`.dark` в `globals.css` на палитру выше, `--radius: 6px`, добавить `--surface-sunken/raised`, `--status-*`, `--accent-soft`, шкалу `--text-*`; прокинуть в `@theme inline`. Экраны на shadcn-переменных перекрасятся сами. Починить `themeColor` в `layout.tsx` (сейчас тёмный `#0b0b0b` при белом UI) и `title`. Сразу же: русификация всех строк (словарь в одном модуле), эмодзи → lucide, резолв telegram ID → имя в одном хелпере.
3. **Реальные роуты.** Разнести `useState<Section>` из `page.tsx` на сегменты: `/tasks`, `/meetings`, `/meetings/[uid]`, `/knowledge`, `/team`, `/settings`, `/admin`. **Блокер deep link:** при `output: "export"` динамический `/meetings/[uid]` не собирается — либо уходить со static export (next-on-pages/OpenNext на CF), либо SPA-fallback через `_redirects` + клиентский разбор URL, либо query-параметр `/meetings?uid=…`. Плюс парсинг `start_param` для Mini App (`t.me/<bot>/<app>?startapp=m_<uid>`) и return-to после `/login`. Решить ДО вёрстки страницы встречи.
4. **AppShell.** `lg:` — сайдбар (за основу sidebar-блок shadcn, токены `--sidebar-*` уже в globals.css) + скрыть BottomNav (`lg:hidden`); ниже — обновлённый таб-бар, FAB, шиты. `DetailSurface` (panel/sheet) вместо текущих Dialog.
5. **Встречи: split view + страница-редактор.** `MeetingsScreen` → `MeetingsList` + `MeetingPage`; контент `MeetingDetailDialog` переезжает в `MeetingPage` и расширяется до состава спеки 05. Это одновременно и есть веб-редактор для transcribator — два дела одним PR.
6. **⌘K + плотность.** Палитра на `cmdk` поверх `searchEntries`; пасс плотности (36px строки, mono-метаданные, hover); деталь задачи → drawer.
7. **Telegram-мост и полировка.** `colorScheme`/`MainButton`/`BackButton`/haptics в `TelegramProvider`; тёмная тема как полноправный гражданин; `sw.js` — network-first для navigation (сейчас cache-first отдаёт старую оболочку после деплоя); моки DEV_MODE — из прод-бандла в отдельный модуль.

Шаги 1–2 дают видимый эффект в первый день и не трогают логику; 3–4 — каркасная неделя; 5 закрывает зависимость transcribator от веба.

## Definition of Done дизайна

- [ ] Ни одного экрана с системным serif; Golos/Mono грузятся с кириллицей, `font-display: swap`
- [ ] Десктоп ≥1024: сайдбар, контент ≤1680px, ноль fixed-кнопок во всю ширину, BottomNav скрыт
- [ ] Мобила: таб-бар ≤5 пунктов, шиты, MainButton/BackButton в Mini App, safe-area
- [ ] `/meetings/[uid]` открывается по ссылке из уведомления: браузер И Mini App (startapp)
- [ ] Все строки UI на русском, единый словарь; ни одного сырого telegram ID; ни одного эмодзи-икона
- [ ] Статусы встреч/задач/агента — одна четвёрка цветов на всех трёх поверхностях
- [ ] Светлая и тёмная темы осознанные; `colorScheme` Telegram синхронизирован
- [ ] Скриншоты 320/768/1024/1440 без переполнений; фокус-состояния видимы с клавиатуры
