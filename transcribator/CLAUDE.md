# CLAUDE.md — Swarm Meetings

Инструкции для Claude Code. **Источник истины по принятым решениям — `10-REVISED-DESIGN.md`** (флоу, контракт, аутентификация, модель данных). Прочитай его перед любой работой; остальные доки 00–07/09 — исторический контекст, при конфликте приоритет у `10`. UI всех поверхностей — `08-UI-UX-V2.md`.

## Контекст в одном абзаце

Делаем замену Read.ai/Granola для внутренней команды (~20 чел): записываем онлайн-звонки, транскрибируем, делаем тезисы, человек вычитывает, публикуем в командную базу знаний Swarm Brain **или** в личное хранилище, авто-извлекаем задачи. Рекордер — **своё лёгкое macOS-приложение** (Swift/AppKit меню-бар, ScreenCaptureKit — системный звук удалённых участников + AVAudioRecorder — микрофон владельца → две дорожки AAC m4a; папка `recorder/`). Агент пишет встречу и шлёт **АУДИО** в Supabase edge-функцию `meeting-ingest` (репо `GarroV/Swarm-brain`, проект Supabase `vbqglndbxkpmreccpqmr`). Транскрибация **и** тезисы — **в облаке**: сервер транскрибирует обе дорожки через OpenAI `/v1/audio/transcriptions` (`whisper-1`, `verbose_json` → сегменты с таймстампами), сводит по таймстампам с метками собеседник/я, затем GPT-4o генерит тезисы по командному шаблону. Человек правит тезисы в веб-версии (Next.js на Cloudflare Pages) и аппрувит с выбором базы. Стоимость облака ~$0.36/час встречи + центы на тезисы; причина облака — не тащить тяжёлый локальный ML и GPU на машины пользователей.

## Жёсткие принципы (нарушение = переделка)

1. **Агент — тупой.** Никакой генерации тезисов, шаблонов, LLM-логики на клиенте. Только: запись → `claim` → загрузка аудио.
2. **Контракт API (`10-REVISED-DESIGN.md §7`) — закон.** Менять только синхронно с обеих сторон и с версионированием (`agent_version`).
3. **Каждая встреча проходит обязательную вычитку + ручной аппрув + выбор базы (команда/личное).** Никакого «доверенный источник минует вычитку». Это ядро, не обсуждается.
4. **Идемпотентность и защита человеческой правки.** Дедуп — по ключу реальной встречи (`identity_key`: calendar/room, manual — без авто-дедупа). Правленые человеком тезисы (`notes_edited_at != null`) сервер при повторной заливке не перезаписывает.
5. **Переиспользуй существующее в Swarm-brain.** Перед написанием хелперов (запись в базу знаний, эмбеддинги, задачи, Telegram-отправка, аутентификация) — изучи `supabase/functions/read-ai-webhook/`, `swarm-bot/` и `_shared/`, бери их паттерны и утилиты. Доступ к `entries` — только через `swarm-api/entries-guard.ts` (см. корневой `CLAUDE.md`).
6. **Все секреты — в Supabase secrets.** Ничего в код и git. `WEB_BASE_URL=https://swarm-brain.pages.dev` уже выставлен (кнопка «Открыть» в уведомлении).

## Стек и команды

- **Swarm-brain (бэкенд):** Deno, Supabase Edge Functions (задеплоено на прод). Функции встреч: `meeting-claim`, `meeting-ingest`; ревью/публикация — в `swarm-api` (`GET/PATCH /agent-meetings*`, `POST /agent-meetings/:id/publish`). Деплой: `supabase functions deploy <fn>`. Секреты: `supabase secrets set`.
- **Рекордер (`recorder/`):** Swift/AppKit, меню-бар (`LSUIElement`), минимальная macOS 13, bundle id `io.dodobrands.swarmrecorder`. Собирается **без полного Xcode**: SwiftPM + ручная сборка `.app`-бандла + ad-hoc codesign (`build-app.sh`); Xcode-проект не обязателен. Источники: `SwarmTypes`, `SwarmClient` (claim+upload+ретраи), `AudioRecorder` (две дорожки), `Permissions`, `AppDelegate`, `main`. Режим `--selftest` прогоняет весь цикл (доказан e2e).
- **Веб:** Next.js 16 + Tailwind 4 + shadcn/Base UI в существующем веб-слое Swarm-brain (`miniapp`), static export на Cloudflare Pages (`swarm-brain.pages.dev`).

## Аутентификация агента

Персональный `smcp_`-токен (механизм уже в проекте: `/mytoken`, `/revoketoken`, SHA-256-хэш в `allowed_users`). `Authorization: Bearer <token>`; верификация в `_shared/agent-auth.ts` (`verifyAgentToken` → `{telegramId, groupId}`). Личность **и** `group_id` берутся из токена, не из payload — нет спуфинга. Не статический общий секрет.

## Стиль работы

- Русский язык в пользовательских текстах (UI рекордера, уведомления, тезисы), английский — в коде/комментариях/идентификаторах.
- Перед деплоем — `deno check` затронутых функций (см. корневой `CLAUDE.md`, pre-commit хук).
- Если реальная схема БД отличается от описаний в доках — авторитетна миграция `supabase/migrations/20260612000000_meetings.sql` и код; доку правь под реальность.

## Чего НЕ делать

- Не добавлять фичи вне MVP (диаризация по говорящим, авто-апдейтер рекордера, Windows).
- Не делать вторую реализацию поиска/задач/чата на клиенте — всё это уже есть в Swarm Brain; правка тезисов живёт в вебе.
- Не трогать существующие функции `swarm-bot` / `swarm-mcp` без необходимости; `read-ai-*` не удалять до полного отключения Read.ai (конец месяца). Granola продолжает работать в переходный период — три источника уживаются через `source`-фильтры (`read_ai`, `granola`, `desktop-agent`).
