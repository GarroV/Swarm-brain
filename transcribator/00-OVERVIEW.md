# Swarm Meetings — обзор проекта

Внутренний инструмент команды: автоматическая запись и транскрибация встреч на маках сотрудников, генерация тезисов на стороне Swarm Brain, правка и менеджмент заметок в веб-версии.

Заменяет связку Read.ai / Granola. Без подписок: единственные внешние расходы — уже используемый OpenAI API (текст, не аудио).

## Компоненты

| Компонент | Что это | База |
|---|---|---|
| **Desktop Agent** | Тонкий фоновый агент в меню-баре macOS: детект встреч по календарю, запись звука, локальная транскрибация, отправка в рой | Форк `fastrepl/anarlog` (MIT, Tauri/Rust) |
| **meeting-ingest** | Edge-функция Supabase: приём транскрипта, генерация тезисов (GPT-4o), экстракция задач, эмбеддинги | Существующий стек Swarm Brain (Deno, по образу `read-ai-webhook`) |
| **Web Editor** | Страница заметки встречи: просмотр/правка тезисов, история встреч | Next.js (существующий Mini App / веб-слой роя) |
| **Дистрибуция** | .pkg с запечённым конфигом, раздача через общий диск | pkgbuild, без Apple Developer аккаунта |

## Зафиксированные решения (не пересматривать без причины)

1. **Источник кода агента:** `fastrepl/anarlog` (история: Hyprnote → Char → Anarlog). MIT, активен (коммиты июнь 2026). Пиннимся на стабильный коммит, изменения держим изолированными.
2. **Без живых субтитров.** Во время звонка — только запись аудио в файл (почти нулевая нагрузка). Транскрибация — batch после окончания встречи.
3. **Целевое железо:** минимум Apple M1 / 8 ГБ RAM. Модель Whisper: `large-v3-turbo` квантованная (q5, ~600 МБ файл, ~1 ГБ RAM в работе). Язык: русский — приоритет качества.
4. **Тезисы генерятся на сервере** (GPT-4o, командный шаблон), не на клиенте. Шаблоны меняются в одном месте без обновления клиентов.
5. **Поле для заметок во время встречи — есть.** Пометки пользователя (`user_notes`, с таймстампами строк) уезжают на сервер и используются как акценты при генерации тезисов (паттерн Granola "enhance").
6. **Правка тезисов — в веб-версии**, не в десктопе. Записи из агента идут с `source: "desktop-agent"` и минуют существующую серверную проверку тезисов (правит человек напрямую).
7. **Upsert по `meeting_id`** — повторная отправка перезаписывает, не дублирует.
8. **Транскрипт хранится и эмбеддится вместе с тезисами** — усиливает семантический поиск.
9. **Аудиофайлы:** локально на машине пользователя, ротация 7 дней, автоудаление.
10. **Дистрибуция без $99 Apple Developer:** pkg раздаётся через общий диск / SMB (нет quarantine-атрибута → Gatekeeper молчит).

## Поток данных

```
Календарь → Agent детектит встречу
  → окно: поле заметок + индикатор записи
  → запись systemaudio + mic в WAV
Встреча закончилась
  → Whisper large-v3-turbo (q5) batch-транскрибация (M1: ~3–5 мин на час встречи)
  → POST /meeting-ingest {transcript, user_notes, meta}
Supabase Edge Function
  → GPT-4o: тезисы по командному шаблону (с учётом user_notes)
  → экстракция задач → таблица tasks
  → эмбеддинги (text-embedding-3-small) → pgvector
  → push-уведомление "Тезисы готовы" + ссылка
Пользователь
  → открывает веб / Mini App → правит тезисы → сохранение (upsert)
Дальше работает существующий даунстрим Swarm Brain:
  бот, /tasks, семантический поиск, MCP (get_meetings, search_knowledge)
```
