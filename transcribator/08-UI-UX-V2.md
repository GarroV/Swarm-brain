> **Статус и приоритет (важно).** Это UI/визуальный слой. Источник истины по **флоу, навигации и API-контракту** — `10-REVISED-DESIGN.md`, `02-API-CONTRACT.md`, `05-WEB-EDITOR-SPEC.md`; при конфликте приоритет у них. В частности:

Везде ниже, где встречается `/meetings/[uid]`, читай это как query-deep-link: динамический файловый роут нереализуем при `output: export` и не используется.
> - Приёмы «Перегенерировать тезисы», ⌘J «правка разговором» и «Подтвердить» — **форвард-предложения**: на бэке их пока нет, они требуют новых эндпоинтов `swarm-api` и обязаны уважать защиту `notes_edited_at` (без слепой перезаписи правок человека).
> - Параллельно оценивается свежий дизайн-хендофф `design_handoff_roy` (от Claude Design), который может заместить части этой системы.

> Финальная премиум дизайн-система. Это **спецификация для разработчиков**, не мудборд.
> Заменяет направление из `08-UI-UX.md` («Плотный рабочий инструмент») — не переписывает его, а доводит до зрелости через дисциплину, а не декор.
> Палитра, шрифты (Golos Text + JetBrains Mono), radius 6px уже отгружены в `globals.css` и `layout.tsx`. Строим **поверх**.
>
> **Главная идея:** интерфейс — это типографский гроссбух. Спокойная бумага под длинный русский текст; всё структурное — hairline-линиями и ступенями поверхностей; единственное цветное пятно на экран — медовый акцент главного действия; метаданные — моноширинные «поля документа». Контент важнее хрома; хром проявляется на hover.
>
> **Почему именно так:** ядро Swarm — длинные русские тезисы, транскрипты, семантическая база. Это **читательский** продукт под видом рабочего инструмента. Granola: документ-холст > дашборд. Notion: тёплая серая шкала + контролируемая длина строки = «дорого». Linear/Vercel: рацион цвета + borders-first + табличные цифры = «зрело». Берём редакционное спокойствие как базу, накладываем плотность списков и клавиатурную скорость Linear/Superhuman.

## 1. Принципы и референсы

### Референсы (что и зачем берём)

| Продукт | Что берём |
|---|---|
| **Granola** | Документ-холст вместо дашборда; авторство кодируется цветом текста (AI = тусклее, человек = темнее); группировка встреч по людям |
| **Notion** | Тёплая серая шкала; контролируемая длина строки (≤72ch); тело документа дышит (16/26) |
| **Linear** | Рацион цвета; borders-first глубина; SVG-иконки прогресса (форма несёт смысл); плотные строки; клавиатурный паритет |
| **Vercel / Geist** | Детерминированная gray-лестница (1..10) с фиксированными ролями; бейдж-счётчик в навигации; статус во вкладке/favicon |
| **Superhuman** | Плотные строки списков; непрочитанное = border-left, не заливка фона; `j/k`-навигация |
| **Stripe** | Табличные цифры как тихий финансовый сигнал; card-less секции (карточки «бурят» данные) |

### Принципы (ревью-чеклист — занести комментарием в `globals.css`)

1. **Один filled-акцент на видимую зону.** Медовый `--accent` — ровно одна primary-кнопка (главное действие экрана) + активная навигация. Всё прочее — `ghost`/`outline` на нейтралях. >1 заливного медового пятна на экране = баг. Статусы НЕ заливка кнопок — только точки/иконки/бейджи.
2. **Глубина — borders-first.** Hairline-бордеры + 3–4 ступени поверхностей. Тени — ТОЛЬКО у плавающих слоёв (⌘K, поповеры, шиты, модалки). У карточек и строк — никогда.
3. **Два режима плотности.** Списки/доски — плотные строки 36px (desktop). Тело документа (тезисы, транскрипт, превью базы) — дышит: 16/26, узкая колонка ≤72ch, щедрые поля. Density — на рельсы и списки, не на тело.
4. **Цвет = смысл, не декор.** Четыре статус-цвета (done/progress/pending/danger) + детерминированный hue рынков. Никаких `text-green-500`/`amber-500` Tailwind в oklch-продукте — только токены.
5. **Авторство кодируется цветом текста** (Granola): человеческое — `--foreground`, AI-сгенерированное — `--text-secondary`. Без рамок и бейджей.
6. **Клавиатура паритетна мыши.** Любое действие — хоткеем; ⌘K и контекст-меню обучают хоткеям. Оптимистичный UI 0.1–0.3s.
7. **Радиус кодирует «приподнятость» объекта.** 4 ступени, заметный разброс.
8. **Mono-голос — фирменный.** Mono-лейблы секций (uppercase, трекинг +0.04em) и mono-якоря `[12:34]` — на ВСЕХ поверхностях, не только на странице встречи. Так «гроссбух» читается как намеренный голос, а не как осторожность.
9. **Русский всюду, единый словарь, ноль эмодзи-иконов, ноль сырых telegram ID.**

### 2.1 Цвет — нейтральная gray-лестница (Geist-стиль, 10 ступеней, тёплый hue 90)

#### Цвет рынков (HU, RS, ME — ~25 стран), детерминированный, пастельный

Урок Notion: снижаем хроматику, иначе 25 пилюль = цветовой шум.

```ts
// lib/market-color.ts
const hue = (hash(code) % 360);
// light пилюля: фон oklch(0.945 0.04 H), текст oklch(0.40 0.05 H)
// dark пилюля:  фон oklch(0.30 0.045 H),  текст oklch(0.82 0.05 H)
// граф / точка: oklch(0.62 0.05 H)  — тот же hue, чтобы рынок совпадал по цвету везде
```

Радиус пилюли рынка/типа — **6px (`--radius`), НЕ full**. Full остаётся статус-точкам и аватарам. Так цвет читается как данные, а не как тег-облако.

### 2.2 Типографика — кириллическая шкала (Golos Text + JetBrains Mono)

Иерархия — **весом и размером в узком диапазоне** (Linear/Raycast-механика), не сменой гарнитуры. Ключевое усиление: **отрицательный трекинг на крупных кеглях** (даёт «дорогой собранный» вид) и **положительный на mono-мете 11px** (делает таймстампы сканируемыми). Вес h1 снижен с 750 → 600–650 (750 на 13px-базисе тяжёл).

```css
@theme {
  /* Семейства уже подключены в layout.tsx */
  --font-sans: var(--font-sans);        /* Golos Text 400–800 */
  --font-mono: var(--font-geist-mono);  /* JetBrains Mono */

  /* Трекинг — носитель «дороговизны» */
  --tracking-tight:  -0.02em;   /* на --text-xl/2xl */
  --tracking-snug:   -0.011em;  /* на --text-lg */
  --tracking-mono:    0.01em;   /* JetBrains Mono метаданные — стянуть таймстампы [12:34] */
  --tracking-label:   0.04em;   /* mono uppercase-лейблы «ДАТА / ИСТОЧНИК» */
}
```

| Токен | Размер/LH/вес | Трекинг | Шрифт | Применение |
|---|---|---|---|---|
| `--text-xs` | 11/16 · 400 | +0.01em | Mono | таймстампы транскрипта `[12:34]`, хоткеи, коды рынков, счётчики |
| `--text-label` | 11/14 · 600 UPPERCASE | +0.04em | Mono | лейблы метаданных «ДАТА · ДЛИТЕЛЬНОСТЬ · ИСТОЧНИК», заголовки секций ⌘K и встречи |
| `--text-sm` | 12/16 · 400 | 0 | Golos | вторичные подписи, бейджи |
| `--text-base` | 13/20 · 400 | 0 | Golos | строки списков, тело UI (desktop) |
| `--text-row` | 13/20 · 600 | -0.005em | Golos | название в строке списка (вес «отправителя») |
| `--text-md` | 15/22 · 400 | 0 | Golos | тело UI mobile |
| `--text-read` | 16/26 · 400 | 0 | Golos | **тело тезисов / транскрипта / документа** (Notion 1.55) |
| `--text-lg` | 18/24 · 600 | -0.011em | Golos | заголовки панелей, название встречи в детали, H1 внутренних экранов |
| `--text-xl` | 24/30 · 600 | -0.02em | Golos | заголовок страницы-редактора (вниз с 700) |
| `--text-2xl` | 32/38 · 650 | -0.02em | Golos | h1 топ-экранов (вниз с 750) |

**Табличные цифры** (тихий финансовый сигнал Stripe):

```css
.nums { font-variant-numeric: tabular-nums; }
/* + font-feature-settings: 'tnum' 1 по умолчанию на mono-классах */
```

Все даты / длительности / дедлайны / счётчики — tnum, правое выравнивание в колонках списков.

> **ВАЛИДАЦИЯ ПЕРЕД ФИКСАЦИЕЙ ЗНАЧЕНИЙ (обязательно):** отрицательный трекинг на кириллице Golos ведёт себя иначе, чем на латинице. Перед коммитом токенов прогнать `--text-2xl` (32/650 -0.02em), `--text-xl` (24/600 -0.02em) и mono-мету 11px на реальной русской строке (например «Синхронизация по Болгарии · 47 мин · desktop-agent») в браузере — chrome-devtools screenshot на 320 / 768 / 1440 + dark. Если буквы «слипаются» на крупном кегле — поднять трекинг до -0.015em.

  --space-wide:    48px;  /* крупные разрывы, padding пустых состояний */

- Высота строки списка: **36px desktop / 48px mobile** (touch-таргет ≥44px).

- Контент-зона ≤1680px (канбан/таблицы); текстовые экраны ≤72ch.

### 2.4 Radius — кодирует «приподнятость» (заметный разброс)

Проблема сейчас: shadcn-`@theme inline` задаёт radius через `calc()` от 6px (sm=0.6×=3.6px, md=0.8×, lg=1× ... xl=1.4×=8.4px) — разрыв слишком мал, глаз не считывает иерархию. Развести в **плоские пиксельные** значения (переопределить блок):

```css
@theme {
  --radius:     6px;     /* базовый: контролы, кнопки, инпуты, строки */
  --radius-sm:  4px;     /* бейджи, keycap-хинты, статус-пилюли */
  --radius-lg: 10px;     /* карточки канбана, превью базы */
  --radius-xl: 14px;     /* шиты, модалки, ⌘K-палитра */
  /* пилюли/аватары — 9999px (full) */
}
```

> При замене учесть, что shadcn-компоненты ссылаются на `--radius-md`/`--radius-lg` — оставить `--radius-md: 6px` алиасом, чтобы ничего не съехало.

### 2.5 Тени / глубина — borders-first

Уровень 0 (карточки, строки): **только `--border`, тени НЕТ**. На dark hairline через inset-shadow (не ест 1px layout, резче на oklch-фоне). Плавающие слои — многослойный depth-stack (Notion/Linear «дорогая мягкость»), не одна жёсткая тень, с отрицательным spread (тень собрана под объектом):

```css
@theme {
  --hairline-inset: inset 0 0 0 1px var(--border);  /* для dark-строк вместо border */
  --shadow-overlay:                                   /* поповеры, ⌘K, drawer */
    0 1px 2px oklch(0 0 0 / 4%),
    0 4px 12px -2px oklch(0 0 0 / 6%),
    0 12px 32px -8px oklch(0 0 0 / 10%);
  --shadow-modal:                                     /* модалки, шиты */
    0 2px 4px oklch(0 0 0 / 4%),
    0 8px 24px -4px oklch(0 0 0 / 8%),
    0 24px 56px -12px oklch(0 0 0 / 16%);
  /* dark: тени почти убрать, глубину держать ступенями --surface-* */
}
```

### 2.6 Движение (быстрое и редкое, compositor-only)

```css
@theme {
  --duration-fast:   120ms;  /* hover строк, проявление контролов */
  --duration-normal: 180ms;  /* drawer/sheet/⌘K вход, fade тезисов */
  --ease-out:       cubic-bezier(0.16, 1, 0.3, 1);   /* единственный UI-easing */
  --ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1);   /* входы панелей */
}
```

- Только `transform` / `opacity` / `color` / `clip-path`.
- **Запрет** `scale`-подпрыгиваний на `:active`/`:hover`.
- `prefers-reduced-motion` → мгновенная смена состояния.
- Пульс «готовим тезисы» — только `opacity` точки `--status-progress`.
- Stagger появления AI-тезисов после генерации: `opacity` + `translateY(4px)`, ~40ms между секциями.
- Хаптика на смену статуса в Mini App.

### Скелетоны — точная геометрия контента (не спиннер)
Под каждую поверхность: список = N строк 36px с блоками на месте точки/названия/mono; страница встречи = абзацы колонки ≤72ch; канбан = колонки × карточки. CSS-анимация opacity (compositor), резерв высоты → CLS≈0.

### Контекст-меню (паритет клавиатуры) + тосты
Base UI / shadcn ContextMenu на строках встреч/задач/базы дублирует действия + хоткеи справа. **Mobile:** контекст-меню → long-press. Оптимистичные мутации везде + sonner-тост «Готово · Отменить (Z)» вместо confirm-модалок для обратимого (sonner мобилен — работает на обеих поверхностях).

### Состояния focus / hover / active (единые)
- **focus-visible:** `ring-2 ring-[--accent-ring] ring-offset-2 ring-offset-[--background]`, без `outline`. Виден только при клавиатуре.
- **hover:** строки → `--surface-sunken`; кнопки ghost → `--accent-soft`; 120ms `--ease-out`.
- **active:** затемнение фона на ступень (`--gray` +1), **без** `scale`.
- **disabled:** `--gray-6` текст, `opacity` не трогаем (мутит фон).

## 5. Что делает это «дорого» (и почему реализуемо на текущем стеке)

1. **Рацион цвета.** Один медовый filled на экран + четыре `--status-*` + пастельные hash-hue рынков. Глаз сразу видит главное действие. Чисто токены — `globals.css` уже наложен на shadcn-переменные, перекраска бесплатна.
2. **Borders-first глубина + многослойные тени только у плавающих слоёв.** Лесенка `--gray-1..10` с фиксированными ролями = предсказуемая глубина без хаоса теней. Чистый CSS.
3. **Кириллическая типографика с характером.** Golos весами 400/500/600/650 + отрицательный трекинг на крупном + положительный на mono-мете + tnum. Шрифты уже подключены — добавляются только трекинг-токены и tnum-utility.
4. **Два режима плотности.** Списки плотные (36px, скан), документ дышит (16/26, ≤72ch, чтение). Зрелость = разные режимы на одном продукте.
5. **Авторство цветом текста** (Granola) — гибридный AI/человек документ читается честно, без рамок. `data-origin` + один Tailwind-селектор.
6. **Скорость как дизайн-принцип.** Оптимистичный UI, ⌘K + контекст-меню обучают хоткеям, скелетоны точной геометрии, движение 120–180ms compositor-only. Команда ~20 человек в инструменте каждый день — оценит реально.
7. **Mono-голос везде** (лейблы секций + якоря) — фирменная узнаваемость, защита от «неотличимого Notion-клона».
8. **Документ-холст встречи** — единственное радикальное продуктовое решение, доведённое до пикселя: верифицируемые якоря в транскрипт, ⌘J-правка разговором, типизированные секции с выгрузкой задач в трекер (чего нет у Granola). Hero-экран, по которому продукт узнаётся.
