## Риски и планы Б

| Риск | Вероятность | План Б |
|---|---|---|
| Русская транскрипция дефолтным движком anarlog слабая | средняя | Подменить модель на large-v3-turbo / русский файнтюн (конфиг или мини-патч). Крайний случай: owhisper-client → свой faster-whisper сервер |
| В anarlog нет чистого batch-режима | средняя | Патч: запись WAV → по событию конца встречи скормить файл local-stt. Объём — небольшой |
| Таймаут edge-функции на длинных встречах | средняя | Асинхронная генерация через job-очередь (03 §2) |
| 8 ГБ RAM: свопинг во время звонка | низкая (запись ≠ транскрибация) | Уже решено архитектурно; если всплывёт — понизить квант/модель |
| Апстрим anarlog затихнет | средняя, некритично | Код наш (MIT), 600+ форков сообщества; обслуживание = фиксы под новые macOS 1–2 раза в год |
| macOS мажорный релиз ломает захват звука | ежегодная рутина | Подтянуть фикс из апстрима/форков; день-два работы раз в год |
| Сотрудник забыл дать разрешения → встречи молча не пишутся | высокая без защиты | Агент проверяет разрешения при каждом старте; нет разрешения → красный значок в меню-баре + нотификация |
