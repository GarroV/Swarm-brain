# 05 — Web Editor: страница заметки встречи

Живёт в существующем Next.js-слое Swarm Brain (веб-версия / Telegram Mini App). Это основной «дом» заметок: агент только доставляет, человек правит здесь.

## Маршруты

```
/meetings                 — список встреч (новые сверху, бейдж "не просмотрено")
/meetings/[meeting_uid]   — страница заметки (deep link из уведомления агента)
```

Авторизация — существующая схема роя (Telegram auth для Mini App). Доступ к встречам — по тем же правилам, что у бота (admin/superadmin видят всё командное).

## Страница заметки: состав

1. **Шапка:** название, дата/время, длительность, участники, источник (desktop-agent), владелец записи.
2. **Тезисы (главный блок):** markdown-редактор. Просто и надёжно: textarea/просмотр с переключателем или лёгкий md-редактор, без коллаборативного режима в MVP. Кнопка «Сохранить» → PATCH (см. 03-BACKEND-SPEC §4) → проставляется `notes_edited_at`.
3. **Задачи встречи:** список привязанных задач со статусами (переиспользовать данные/логику `/tasks` бота). Кнопка «Обновить задачи из тезисов» — явный повторный прогон экстракции.
4. **Спойлер «Транскрипт»:** read-only, сегменты с таймстампами. Поиск по тексту страницы (ctrl+f достаточно в MVP).
5. **Спойлер «Мои пометки во время встречи»:** raw user_notes с таймстампами.
6. Кнопка «Перегенерировать тезисы» (подтверждение: «Затрёт текущий текст») — на случай неудачной генерации; вызывает генерацию заново из транскрипта.

## Поведение и состояния

- `summary_status: processing` (если генерация асинхронная) → страница показывает «Готовим тезисы…» с автообновлением.
- Конфликт правок (открыли на двух устройствах): last-write-wins + предупреждение, если `notes_edited_at` изменился с момента загрузки. Без CRDT в MVP.
- Mini App: та же страница, адаптив под мобилку — править тезисы с телефона по дороге со встречи должно быть удобно (крупный шрифт, кнопка сохранения снизу).

## Definition of Done (MVP)

- [ ] Ссылка из уведомления агента открывает нужную заметку (и в браузере, и в Mini App)
- [ ] Правка тезисов сохраняется, после неё повторный POST от агента тезисы не затирает
- [ ] Сохранение обновляет эмбеддинги (поиск в боте находит правленый текст)
- [ ] Задачи встречи видны и кликабельны
- [ ] Транскрипт и пометки доступны под спойлерами
- [ ] Работает с телефона в Mini App
