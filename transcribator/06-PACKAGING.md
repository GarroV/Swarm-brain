# 06 — Сборка и дистрибуция (без Apple Developer аккаунта)

Цель UX: «открыла pkg с общего диска → Далее-Далее-Готово → три раза нажала Разрешить → работает». Без терминала, без правки файлов, без Gatekeeper-плясок.

## Сборка приложения

1. `tauri build` в форке → `SwarmAgent.app` (universal или arm64-only — у команды M1+, достаточно arm64).
2. Ad-hoc подпись (бесплатно, без аккаунта): `codesign --force --deep -s - SwarmAgent.app`. Это не нотаризация, но даёт целостность бандла.

## Сборка pkg

```
pkgbuild --root ./pkgroot \
         --identifier com.team.swarmagent \
         --version 0.1.0 \
         --scripts ./scripts \
         SwarmAgent-0.1.0.pkg
```

Состав:
- `pkgroot/Applications/SwarmAgent.app`
- `scripts/postinstall`:
  - кладёт `config.json` (с ingest_url и секретом) в `~/Library/Application Support/SwarmAgent/` для текущего пользователя
  - снимает quarantine на всякий случай: `xattr -cr /Applications/SwarmAgent.app`
  - ставит LaunchAgent (`~/Library/LaunchAgents/com.team.swarmagent.plist`) — автозапуск при логине
  - запускает приложение

## Дистрибуция: ключевое правило

**Раздавать ТОЛЬКО через общий диск (SMB) или физический носитель.** Файлы оттуда не получают quarantine-атрибут → Gatekeeper не вмешивается вообще. Если pkg скачают браузером/из Telegram — quarantine появится, и macOS потребует Privacy & Security → Open Anyway (два клика, не смертельно, но избегаем).

Инструкция для команды (одно сообщение в чат):
> 1. Открой общий диск → папка Tools → SwarmAgent.pkg, двойной клик, Далее до конца.
> 2. Приложение запустится само. Разреши доступ: Микрофон, Запись экрана и звука, Календарь — три системных окна.
> 3. Введи свой Telegram (агент подскажет). Всё, дальше он работает сам.

## Онбординг в приложении (первый запуск)

Визард: 1) скачивание STT-модели с прогрессом (~600 МБ) → 2) запрос разрешений по очереди, каждое со скриншотом и кнопкой, открывающей нужную панель System Settings (микрофон, Screen/Audio Recording, календарь, уведомления) → 3) ввод/выбор Telegram ID → 4) «Готово, я в меню-баре». Разрешения нельзя выдать программно — только провести человека.

В anarlog онбординг с разрешениями уже есть (см. их permissions-плагин) — адаптировать, не писать с нуля.
